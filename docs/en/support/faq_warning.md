# Warnings and Notices FAQ

> This section covers common warning and notice problems that occur while msModelSlim is running. To add a new entry, append it at the end of the document in the order `1.`, `2.`, and keep the three-section structure "Symptom / Cause / Solution / Related Documents (Optional)" (the subsection numbers within a section run from `x.1` to `x.3`).

## 1. Why Is the "sys:1: DeprecationWarning: builtin type swigvarlink has no module attribute" Warning Reported When Quantization Ends?

### 1.1 Symptom

The following warning appears when quantization ends:

```text
sys:1: DeprecationWarning: builtin type swigvarlink has no module attribute
```

### 1.2 Cause

Third-party libraries generated by an old version of SWIG (Simplified Wrapper and Interface Generator) are incompatible with Python 3.10+.

### 1.3 Solution

This warning does not affect the quantization result. It can be eliminated by upgrading the third-party library that triggers it (such as sentencepiece).
