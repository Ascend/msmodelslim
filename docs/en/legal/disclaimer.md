  - When you use the msModelSlim tool, the tool typically reads model weights downloaded from the internet from the hard disk (via command-line parameters or configuration files provided by you). Using untrusted model weights may lead to unknown security risks. It is recommended that you verify the trustworthiness of model weights through methods such as SHA256 checksum before passing them to the tool.

  - For security and the principle of least privilege, you should not use the msModelSlim tool with high-privilege accounts such as root. It is recommended that you install and run it with a regular user account.

    - Users shall ensure the principle of least privilege on their own (for example, prohibit write access by other users, such as prohibiting 666 and 777).

    - When using the msModelSlim tool, ensure that the umask value of the executing user is greater than or equal to 0027; otherwise, the permissions of the directory and files where the generated quantized model data resides will be excessively permissive.

      - To view the umask value, run the following command: umask

      - To modify the umask value, run the following command: `umask <new value>`

    - Ensure that the original model data and the quantized model data are stored in the current user's directory that contains no symbolic links; otherwise, security issues may arise.

  - Data processing and deletion: Data generated by users during the use of this tool falls within the scope of user responsibility. Users are advised to delete relevant data in a timely manner after use to prevent information leakage.

# To Data Owners

If you do not wish your dataset to be mentioned in the models of msModelSlim, or wish to update the description of your dataset in the models of msModelSlim, please submit an issue on Gitcode. msModelSlim will delete or update the description of your dataset according to your issue. We sincerely appreciate your understanding of and contribution to msModelSlim.
