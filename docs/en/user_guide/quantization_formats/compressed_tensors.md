# compressed-tensors Format Specification

<!-- md-trans-meta sourceCommit=42700c3176a36e2f9012328da12ee6c6ecba2a1b translatedAt=2026-08-20T03:17:27.419Z pushedAt=2026-08-20T03:18:43.393Z -->

## Overview

compressed-tensors is a quantized weights format compatible with the HuggingFace/vLLM ecosystem, and its field conventions follow the [vllm-project/compressed-tensors](https://github.com/vllm-project/compressed-tensors) specification. msModelSlim **embeds** the structural definitions of this specification **during export**, so the quantization process does **not** require installing the `compressed-tensors` package.

**Applicable scenarios**: inference frameworks such as vLLM that support HF `config.json` → `quantization_config`.

## YAML Configuration

Configure the following in `spec.save` of the one-click quantization YAML:

```yaml
spec:
  save:
    - type: "compressed_tensors"
      part_file_size: 4
```

### Configuration Parameters

| Name | Type | Default Value | Description |
|------|------|--------|------|
| `type` | string | `"compressed_tensors"` | Saver type identifier, a fixed value |
| `part_file_size` | int | `4` | Weight shard size (GB); sharding is performed when > `0`, and `0` indicates no sharding |

## Export Artifact Structure

```text
save_directory/
├── config.json                          # Injected with quantization_config field
├── model.safetensors                    # Or sharded: model-00001-of-xxxxx.safetensors
├── model.safetensors.index.json         # Generated when sharded
└── (HF auxiliary files copied from the source model)
    └── *.json / *.py / *.txt / *.jinja
```

**Export process**: safetensors tensors are written between layers, and in the final stage, `quantization_config` is reverse-inferred from the quantized QIR model and written to `config.json`.

## config.json → quantization_config Structure

`quantization_config` is generated by `QuantizationConfig.to_quantization_config_dict()`. A typical structure is as follows:

```json
{
  "version": "0.13.0",
  "quant_method": "compressed-tensors",
  "sparsity_config": {},
  "transform_config": {},
  "config_groups": {
    "group_0": {
      "targets": ["Linear"],
      "weights": { "num_bits": 8, "type": "int", "strategy": "channel", "symmetric": true, "dynamic": false },
      "input_activations": { "num_bits": 8, "type": "int", "strategy": "tensor", "symmetric": false, "dynamic": false },
      "format": "int-quantized"
    }
  },
  "format": "int-quantized",
  "quantization_status": "compressed",
  "global_compression_ratio": null,
  "ignore": ["re:...(?![.\\w])"],
  "kv_cache_scheme": null
}
```

### Top-level Field Description

| Field | Description |
|------|------|
| `version` | Schema version, fixed to `"0.13.0"` |
| `quant_method` | Fixed to `"compressed-tensors"` |
| `config_groups` | Grouped by unique scheme, with key names such as `group_0`, `group_1`, and so on |
| `format` | Root format, such as `int-quantized` or `mixed-precision` |
| `quantization_status` | `"compressed"` at export time |
| `global_compression_ratio` | Global compression ratio (a floating-point number from 0 to 1), an optional informational field that records the compression ratio of the quantized model relative to the original model. It **does not participate in inference loading**. For msModelSlim, it is not computed currently and always be `null`. |
| `ignore` | A regex list of layer names of the same type that are not quantized |
| `kv_cache_scheme` | KV Cache quantization scheme. **Not supported currently** and always `null` |
| `sparsity_config` / `transform_config` | Empty object placeholders |

## QuantizationScheme (in config_groups)

Each `config_groups` entry describes the quantization scheme for a group of layers. **msModelSlim currently supports only linear layer (`nn.Linear` / QIR FakeQuantLinear) quantization**, so `targets` is fixed to `["Linear"]`.

| Field | Description |
|------|------|
| `targets` | Target module type; **currently fixed to `["Linear"]`** |
| `weights` | Weight quantization parameters (`QuantizationArgs`) |
| `input_activations` | Input activation quantization parameter; `null` when only weight quantization is applied |
| `output_activations` | Output activation quantization parameter |
| `format` | Layer compression format, such as `int-quantized` |

## QuantizationArgs Parameter Description

| Name | Type | Defalut Value | Description |
|------|------|--------|------|
| `num_bits` | int | `8` | Quantization bit width |
| `type` | enum | `"int"` | Quantization type: `"int"` / `"float"` |
| `symmetric` | bool | `true` | Whether to use symmetric quantization |
| `strategy` | enum | Automatic inference | Quantization granularity: `tensor` / `channel` / `group` / `block` / `token` / `tensor_group` / `attn_head` |
| `group_size` | int | `null` | Group size for the group strategy |
| `block_structure` | list[int] | `null` | Dedicated to the block strategy; an integer list of length 2, in the form of `[rows, cols]` |
| `dynamic` | bool | `false` | Whether to use dynamic quantization: `false` static, `true` dynamic; explicitly written by the QIR preset during msModelSlim export, no manual configuration required |
| `actorder` | enum | `null` | Activation ordering (`group` / `weight`, etc.) |
| `scale_dtype` | string | `null` | Data type of the scale tensor (torch dtype string) |
| `zp_dtype` | string | Automatic inference | Data type of the zero-point tensor; exported as `null` for symmetric quantization |
| `observer` | string | Automatic inference | Calibration method; defaults to `memoryless_minmax` for static quantization and `null` for dynamic quantization |
| `observer_kwargs` | object | `{}` | Additional parameters passed to the observer |

## Currently Supported Quantization Presets

msModelSlim currently implements export handlers only for the following QIR modules:

| Preset | QIR Module | weights | input_activations |
|--------|----------|---------|-------------------|
| W8A8 Static | `W8A8StaticFakeQuantLinear` | int8, channel, symmetric, static | int8, tensor, asymmetric, static |
| W8A8 Dynamic | `W8A8DynamicPerChannelFakeQuantLinear` | int8, channel, symmetric, static | int8, token, symmetric, dynamic |

Unquantized `nn.Linear` layers are written directly with the original floating-point parameters, and the corresponding regex is generated in the `ignore` list.

## Safetensors Tensor Naming

### W8A8 Static

| Tensor Name | Data Type | Description |
|--------|----------|------|
| `{prefix}.weight` | int8 | Quantized weights |
| `{prefix}.weight_scale` | float32 | Weight quantization scale (unsqueezed to 2D) |
| `{prefix}.input_scale` | float32 | Activation quantization scale |
| `{prefix}.input_zero_point` | - | Written only when `input_offset != 0` |
| `{prefix}.bias` | float32 | Optional |

### W8A8 Dynamic Per-Channel

| Name | Type | Description |
|--------|----------|------|
| `{prefix}.weight` | int8 | Quantized weights |
| `{prefix}.weight_scale` | float32 | Weight quantization scale (unsqueezed to 2D when 1D) |
| `{prefix}.bias` | float32 | Optional |

> The scale/zero-point of dynamic activations is **not written** to the weight file; it is computed dynamically per-token during inference.

## Current Limitations

- Distributed export is not supported (`support_distributed() = False`).

- KV Cache quantization is not currently supported (`kv_cache_scheme = null`).

- Only the W8A8 Static / W8A8 Dynamic QIRs have handlers.

- More presets (such as W4A8) have reserved constants in the schema, but the export handler is not yet implemented.
