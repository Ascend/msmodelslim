**Configuration Constraints**

- This protocol does not support `adapt_rotation`: the quantization service does not execute `spec.prior`, and the multimodal generation adapter does not implement `AdaptRotationInterface`; keep `prior` empty and do not configure `adapt_rotation` in `process`/`per_expert`.
