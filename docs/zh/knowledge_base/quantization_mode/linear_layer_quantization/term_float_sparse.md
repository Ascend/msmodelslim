# 浮点稀疏量化

> **词条类别**：量化数据格式（[线性层量化](README.md)）<br>
> **英文名称**：Float Sparse<br>
> **应用领域**：大语言模型量化压缩、推理加速<br>
> **承载 IR 类**：`W16A16sLinear`（[`msmodelslim/ir/w16a16s.py`](../../../../../msmodelslim/ir/w16a16s.py)，`nn.Module` 子类，非 `AutoFakeQuantLinear`）<br>
> **导出类型**：`W16A16S`；二次压缩部署形态为 `W16A16SC`<br>

## 1. 概述

浮点稀疏量化（导出类型 `W16A16S`）不降低权重与激活的位宽，而是对权重做**数值稀疏**：把一部分浮点权重的数值置零，其余元素仍保持 [FP16/BF16](../../quantization_basic/term_fp16_bf16.md)。它隔离掉位宽量化误差，让对照实验只反映稀疏这一个维度——前向仍是 16bit 线性层计算，零值由硬件稀疏算子跳过。`W16A16SC` 是 `W16A16S` 的特殊部署形态，在数值稀疏之后再做一次权重压缩，供压缩单元落地。

## 2. 词条介绍

### 2.1 模式规格

| 维度 | 取值 | 说明 |
|------|------|------|
| 量化对象 | 权重 W、激活 A | 均不量化，保持 FP16/BF16 原样参与计算 |
| 位宽 | W 16bit，A 16bit | 无位宽压缩 |
| 数据类型 | FP16/BF16 | 浮点；稀疏来自权重数值置零，不是 `WxAy` 位宽命名 |
| 参数获取方式 | 不适用 | 不产生量化参数；权重为上游稀疏化产出的数值稀疏张量 |
| 量化粒度 | 不适用 | 稀疏按元素幅值置零，无量化粒度概念 |
| 对称性 | 不适用 | 无量化参数 |
| 稀疏形态 | `W16A16S` / `W16A16SC` | `W16A16S` 为数值稀疏导出；`W16A16SC` 为其二次压缩部署形态 |

### 2.2 量化公式

本模式不降位宽、不引入量化误差，作为稀疏量化基线，无量化/反量化公式。其权重与激活保持 16bit（FP16/BF16），承载的是上游稀疏化后、部分元素数值为零的张量。

### 2.3 与其他模式的关系

- **与 [W8A8 稀疏量化](term_w8a8_sparse.md)（压缩路径不同）**
  - 本模式：权重保持 16bit 浮点，把部分数值置零，用于评估置零稀疏单独引入的精度损失。
  - W8A8 稀疏：先做 INT8 量化，再只用 256 档中的子集并二次压缩，不是置零。

- **与 [W8A16 静态量化](term_w8a16_static.md)（同为高精度基线，收益来源不同）**
  - 本模式：W/A 均不量化，收益来自数值稀疏（跳过零值元素）。
  - W8A16：收益来自权重位宽压缩（8bit 访存减半）。二者分别对应稀疏与位宽两条独立的压缩路径。

- **与 [W8A8 静态量化](term_w8a8_static.md)（整数量化方案）**
  - 本模式是置零稀疏基线、零量化误差；W8A8 是整数量化方案。二者压缩路径不同，不宜理解成简单叠加。

### 2.4 适用场景与限制

#### 2.4.1 适用场景

- **稀疏量化精度基线**：评估稀疏方案精度时，作为不受位宽量化干扰的对照。
- **稀疏收益评估**：单独衡量数值稀疏权重在目标硬件上的计算/访存收益。
- **二次压缩部署**：需要硬件压缩单元时，由 `W16A16S` 再导出 `W16A16SC`。

#### 2.4.2 使用限制

- **无位宽压缩收益**：本身不降位宽，不作为最终部署的压缩方案。
- **依赖稀疏硬件支持**：稀疏收益需目标硬件稀疏算子支持，否则与普通 FP16 无异。
- **非量化 IR**：不属于 `AutoFakeQuantLinear` 体系，不参与量化参数的计算与校验。
