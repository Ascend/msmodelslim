# W16A16S 量化

> **词条类别**：量化数据格式（[线性层量化](README.md)）
> **英文名称**：W16A16S Quantization
> **应用领域**：大语言模型量化压缩、推理加速
> **承载 IR 类**：`W16A16sLinear`（[`msmodelslim/ir/w16a16s.py`](../../../../../msmodelslim/ir/w16a16s.py)，`nn.Module` 子类，非 `AutoFakeQuantLinear`）

---

## 1. 概述

W16A16S 严格说不是「量化」模式，而是稀疏量化方案的**精度基线**：权重与激活都保持 [FP16/BF16](../../quantization_basic/term_fp16_bf16.md) 不量化，权重张量承载上游 ADMM 剪枝产出的、已按比例（如 30%）置零的稀疏权重。它隔离掉位宽量化误差，让稀疏方案的对照实验只反映「稀疏」一个维度的收益——前向仍是 [FP16/BF16](../../quantization_basic/term_fp16_bf16.md) 线性层计算，零值元素由硬件稀疏算子跳过。

---

## 2. 词条介绍

### 模式规格

| 维度 | 取值 | 说明 |
|------|------|------|
| 量化对象 | 权重 W、激活 A | 均不量化，保持 FP16 原样参与计算 |
| 位宽 | W 16bit，A 16bit | 无位宽压缩 |
| 数据类型 | FP16 | 浮点 |
| 参数获取方式 | 不适用 | 不产生量化参数；权重为上游剪枝产出的稀疏 FP16 权重 |
| 量化粒度 | 不适用 | 稀疏按元素幅值置零，无量化粒度概念 |
| 对称性 | 不适用 | 无量化参数 |

### 量化公式

本模式不降位宽、不引入量化误差，作为稀疏量化基线，无量化/反量化公式。其权重与激活保持 16bit（FP16/BF16），承载的是上游稀疏化后的张量。

### 与其他模式的关系

- **与 [W8A16 静态量化](term_w8a16_static.md)（同为高精度基线，收益来源不同）**
  - 本模式：W/A 均不量化，收益来自稀疏（跳过零值元素）；是稀疏维度的对照基线。
  - W8A16：收益来自权重位宽压缩（8bit 访存减半）；是位宽维度的对照基线。二者分别对应「稀疏」与「位宽」两条独立的压缩路径。

- **与 [W8A8 静态量化](term_w8a8_static.md)（整数量化方案）**
  - 本模式是稀疏基线、零量化误差；W8A8 是整数量化方案。实际稀疏量化常把二者叠加（稀疏 W8A8），本模式用于评估稀疏单独引入的精度损失。

- **与 [W4A4 动态量化](term_w4a4_dynamic.md)（极致压缩方案）**
  - 本模式完全不压缩位宽、是压缩-精度谱系的精度上界；W4A4 极致压缩位宽、精度风险最高。二者代表谱系的两端。

### 适用场景与限制

#### 1. 适用场景

- **稀疏量化精度基线**：评估稀疏方案精度时，作为不受位宽量化干扰的对照。
- **稀疏收益评估**：单独衡量稀疏权重在目标硬件上的计算/访存收益。
- **精度敏感层**：需要完全保留精度的层，作为量化方案中的保留路径。

#### 2. 使用限制

- **无位宽压缩收益**：本身不降位宽，不作为最终部署的压缩方案。
- **依赖稀疏硬件支持**：稀疏收益需目标硬件稀疏算子支持，否则与普通 FP16 无异。
- **非量化 IR**：不属于 `AutoFakeQuantLinear` 体系，不参与量化参数的计算与校验。
