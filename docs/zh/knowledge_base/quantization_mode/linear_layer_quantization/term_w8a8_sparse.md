# W8A8 稀疏量化

> **词条类别**：量化数据格式（[线性层量化](README.md)）<br>
> **英文名称**：W8A8 Sparse<br>
> **应用领域**：大语言模型量化压缩、推理加速<br>
> **承载 IR 类**：`W8A8StaticFakeQuantLinear`（[`msmodelslim/ir/w8a8_static.py`](../../../../../msmodelslim/ir/w8a8_static.py)）<br>
> **导出类型**：`W8A8S`；二次压缩部署形态为 `W8A8SC`<br>

## 1. 概述

W8A8 稀疏量化（导出类型 `W8A8S`）仍是对线性层权重与激活做 [INT8](../../quantization_basic/term_int8.md) 量化，但权重走**数值稀疏**，而不是把部分元素置零。8bit 通常可以表达 256 个整数档位；W8A8S 并不使用全部 256 档，只使用其中的子集，使权重的有效取值范围小于满量程 8bit。随后再经压缩（导出类型 `W8A8SC`）把这份更窄的码本编码下来，从而得到比普通 [W8A8 静态量化](term_w8a8_static.md) 更高的压缩率。这里的 `S` 不是 `WxAy` 位宽命名的后缀。

## 2. 词条介绍

### 2.1 模式规格

| 维度 | 取值 | 说明 |
|------|------|------|
| 量化对象 | 权重 W、激活 A | 线性层矩阵乘两侧的张量；权重额外做数值稀疏 |
| 位宽 | W 8bit，A 8bit | 与 W8A8 静态量化相同，仍按 8bit 存储与计算 |
| 数据类型 | INT8 | 整数格式；数值稀疏指实际用到的整数档位是 256 档中的子集，不是置零 |
| 参数获取方式 | 静态 | scale/offset 由校准集统计后固化 |
| 量化粒度 | 权重 per-channel；激活 per-tensor | 与 W8A8 静态量化相同 |
| 对称性 | 权重对称；激活对称或非对称 | 与 W8A8 静态量化相同 |
| 稀疏形态 | `W8A8S` / `W8A8SC` | `W8A8S` 为收窄码本的 INT8 导出；`W8A8SC` 为其二次压缩部署形态 |

### 2.2 量化公式

量化与反量化沿用 [W8A8 静态量化](term_w8a8_static.md) 的线性映射。与普通 W8A8 的差别不在公式，而在码本占用：W8A8 可铺满约 256 个整数档；W8A8S 只占用其中子集，权重数值的分布范围更窄、更易压缩。`W8A8SC` 不改变这一量化映射，只是把已经收窄码本的 INT8 权重再编码成压缩单元可加载的形态，压缩率高于 W8A8。

### 2.3 与其他模式的关系

- **与 [W8A8 静态量化](term_w8a8_static.md)（同为 INT8 静态，码本是否收窄不同）**
  - 本模式：INT8 量化后权重只用 256 档中的子集，再经 `W8A8SC` 二次压缩，压缩率高于 W8A8。
  - W8A8 静态：可使用满量程 8bit 档位，压缩主要来自 8bit 位宽本身。

- **与 [浮点稀疏量化](term_float_sparse.md)（压缩路径不同）**
  - 本模式：先做 INT8 量化，再靠收窄码本配合压缩提高压缩率，不是把权重置零。
  - 浮点稀疏：权重保持 16bit 浮点，把部分数值置零，用于评估置零稀疏单独引入的精度损失。

### 2.4 适用场景与限制

#### 2.4.1 适用场景

- **需要比 W8A8 更高压缩率的部署**：在 INT8 量化基础上，用收窄码本再压缩。
- **二次压缩部署**：目标硬件提供压缩单元时，由 `W8A8S` 再导出 `W8A8SC`。

#### 2.4.2 使用限制

- **码本收窄会牺牲表达能力**：实际可用档位少于 256，精度通常略低于满量程 W8A8，敏感层可能需要回退。
- **依赖压缩硬件**：没有压缩单元时，`W8A8S`/`W8A8SC` 相对 W8A8 几乎没有额外部署收益。
- **与静态量化相同的校准依赖**：激活仍是 per-tensor 静态量化，离群值敏感。
