# KV Smooth 缓存平滑算法 量化术语百科词条

> **词条类别**：[离群值抑制算法](../README.md#1-离群值抑制算法)<br>
> **英文名称**：kv_smooth<br>
> **应用领域**：KV Cache 压缩、大语言模型量化压缩<br>

---

## 1. 概述

KV Smooth 是一种面向 KV Cache 量化的离群值抑制算法。它利用 Q/K 点积对互逆缩放的不变性，把 Key 通道中的大幅值迁移到 Query 一侧，在尽量保持注意力打分等价的前提下压缩 Key 动态范围；核心特征是缓存侧范围整形、Q/K 成对补偿和对 RoPE 配对结构的约束，可为 [KVCache Quant](../kvcache_quant/term_kvcache_quant.md) 提供前置平滑。

---

## 2. 词条介绍

KV Cache 量化以降低长序列推理的显存占用为目标，但 Key 张量中的离群值会拉大量化尺度，使多数通道的量化精度严重下降。由于推理时只量化写入 KV Cache 的 `key_states` 而不量化 `query_states`，因此可以将离群值从 `key_states` 迁移到 `query_states`，在保持注意力打分不变的前提下获得更稳健的 KV Cache 量化。

从量化流程中的定位看，该算法更接近量化前的分布整形步骤：先降低离群值对量化尺度的支配，再由后续量化算法完成真正的离散化。这种思路的价值在于不必简单扩大位宽，而是通过重分配、旋转或平滑数值幅度，提高有限量化区间对主体数据分布的利用率。

### 2.1 核心思想

KV Smooth 的核心思想是利用注意力点积中的“互逆缩放不变性”，把 Key 上不利于缓存量化的通道峰值迁移到 Query 一侧。对同一特征通道施加 $K'=K/s$、$Q'=Q\cdot s$ 后，理想情况下 $Q'K'^T=QK^T$，因此注意力 logits 不因该重参数化而改变，而进入 KV Cache 的 K 动态范围得到压缩。

这一思路特别适合“只对 KV Cache 做低比特存储”的场景：K 会长期驻留并随序列长度增长，而 Q 只参与当前步计算、不进入缓存，因此在保持点积等价的条件下，把部分幅度压力从 K 迁移到 Q 往往比让 K 的少量离群通道长期支配缓存量化尺度更划算。对于使用 RoPE 的模型，还必须尊重旋转二维子空间的配对结构，使缩放与旋转保持可交换或等价补偿。

其有效性来自缓存侧和即时计算侧成本不对称：在典型仅量化 KV Cache 的方案中，K 的尺度误差会被长期存储并在后续大量 token 中反复使用，而 Q 不进入缓存。

### 2.2 工作机制

设一个 attention head 在 RoPE 之前的 Query/Key 为 $Q,K$，对特征维引入对角尺度矩阵 $D=\operatorname{diag}(s)$，做 $Q'=QD$、$K'=KD^{-1}$。若后续没有破坏该对应关系的操作，则 $Q'K'^T=QDD^{-1}K^T=QK^T$，所以 softmax 之前的注意力 logits 保持不变。尺度通常根据校准 K 的逐通道峰值构造，用于优先压缩最容易支配缓存量化范围的通道。

RoPE 会把相邻或指定配对的两个坐标作为二维向量进行旋转。一般的非均匀对角缩放与二维旋转并不交换：如果一对 RoPE 坐标使用不同尺度，先缩放再旋转和先旋转再缩放会得到不同结果，从而破坏精确的点积等价。解决思路是在 RoPE 配对维度共享兼容尺度，使 $D$ 在每个二维旋转子空间内等价于标量倍数；GQA 场景还需让 K 的尺度与共享它的多个 Q head 对齐。

### 2.3 数学描述

设缩放向量为 $s$，RoPE 之前的 K、Q 分支输出为 $K$、$Q$，则平滑后的值为：

$$
K' = \frac{K}{s}, \quad Q' = Q \times s
$$

注意力打分保持不变：

$$
Q'K'^T = Q \times s \cdot \left(\frac{K}{s}\right)^T = QK^T
$$

- $K$：写入 KV Cache 前的 Key 表示。
- $Q$：与 Key 参与点积的 Query 表示。
- $s$：由校准 Key 的逐通道幅值统计构造的正缩放向量。

平滑统计通常以每层 Key 的逐通道峰值为依据，并把互逆尺度吸收到 RoPE 之前可等价变换的投影或归一化参数中。

RoPE 约束可直接从二维旋转看出。对某一 RoPE 配对维，旋转矩阵为：

$$
R(\theta)=\begin{bmatrix}\cos\theta&-\sin\theta\\\sin\theta&\cos\theta\end{bmatrix}.
$$

若该二维子空间的缩放为 $D=\operatorname{diag}(s_1,s_2)$，一般有 $R(\theta)D\ne DR(\theta)$；只有 $s_1=s_2$ 时 $D=sI$，才对所有 $\theta$ 与旋转可交换。因此 RoPE 配对坐标需要共享尺度，才能把缩放安全地移动到 RoPE 前后而保持等价。

### 2.4 关键性质

- **注意力分数不变**：缩放迁移保证 $QK^T$ 不变，不改变注意力打分。
- **缓存侧离群值迁移**：Key 峰值被压低，对应幅度被迁移到 Query；在仅量化 KV Cache 的典型场景中可降低缓存侧量化压力。
- **RoPE 配对处理**：利用 RoPE 通道成对旋转的性质，在配对通道间取最大后恢复。
- **平滑强度可调**：缩放强度决定从 Key 向 Query 迁移多少动态范围。
- **RoPE 约束**：旋转配对维必须共享兼容尺度，否则互逆缩放与 RoPE 不能保持精确等价。

但尺度不能无限增大。过强平滑会让 Q 的幅值变得过大，可能影响 Q 本身的低精度算子、数值稳定性或其他联动量化；RoPE 配对约束若处理错误则会直接破坏 $QK^T$ 等价。

### 2.5 适用场景

- KV Cache 量化（如 [KVCache Quant](../kvcache_quant/term_kvcache_quant.md)）前需要抑制 Key 离群值、提升缓存量化精度的场景。
- 长序列推理场景下，需要压缩 KV Cache 动态范围以降低显存占用的场景。

更具体地说，这类算法适合“量化误差主要由少数大幅值通道或 token 拉高尺度”的情况。若问题来源并不是离群值，而是模型本身对低比特表示普遍敏感，则单独增加平滑或旋转强度通常收益有限，应结合更高精度量化或敏感层回退。

### 2.6 使用限制

- 算法要求在 RoPE 前后能够建立 Q/K 对应通道的等价缩放关系；若模型结构在两者之间插入会破坏该关系的非线性变换，则不能直接套用互逆缩放。
- 对使用 GQA/MQA 的结构，需要保证共享同一 Key Head 的 Query Head 与其尺度对应，否则会破坏原有注意力点积关系。
- 基于 RoPE 成对通道规约的假设，非 RoPE 结构需谨慎评估。
- 基于仅量化 KV Cache 的 `key_states`/`value_states`、不量化 `query_states` 的假设。

这些限制反映了算法对模型结构和等价变换条件的依赖。若目标模型不满足相应结构假设，强行套用可能破坏原有计算关系；因此遇到不兼容结构时应优先缩小作用范围或使用模型已验证的配方，而不是盲目增大平滑强度。
