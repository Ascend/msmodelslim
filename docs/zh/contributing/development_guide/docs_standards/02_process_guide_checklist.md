# 流程指南校验清单

> 用于校验基于[《流程指南模板》](02_process_guide_template.md)新建或整改的文档。通用校验条目与校验机制（使用说明 / 校验执行 / 豁免机制）见[《公共校验清单》](00_common_checklist.md)；以下为流程指南类型专属校验条目，按严重级别分表。

## 1. 校验条目

### 1.1 ERROR（必须满足）

| 编号 | 校验条目 | 判定条件 | 处理建议 |
| :--- | :--- | :--- | :--- |
| PG-001 | 核心章节 | 存在“适用范围”“输入和交付件”“操作步骤”三个核心章节。 | 补齐缺失章节 |
| PG-002 | 输入与交付件 | “输入和交付件”章节同时包含至少一个输入项和至少一个交付件项。 | 补充输入或交付件项 |
| PG-003 | 操作步骤 | “操作步骤”章节包含至少一个步骤，且每个步骤同时包含“操作”和“输出”。 | 补充步骤或操作、输出 |

### 1.2 WARN（建议满足）

| 编号 | 校验条目 | 判定条件 | 处理建议 |
| :--- | :--- | :--- | :--- |
| PG-004 | 标题与范围 | 标题能表达流程主题；适用范围说明适用对象、场景或边界。 | 调整标题或适用范围 |
| PG-005 | 输入与交付件 | 输入和交付件可定位，说明必要的来源、约束或验收方式。 | 补充来源、约束或验收方式 |
| PG-006 | 步骤闭环 | 步骤顺序合理；按需要补充输入、执行前检查、通过条件、审计记录和异常处置。 | 补充步骤要素 |
| PG-007 | 命令与引用 | 命令、变量和路径有必要说明；引用的能力有证据来源。 | 补充说明或证据来源 |
| PG-008 | 特殊场景 | 涉及精度、性能、安全、产品形态、资源、发布或运行时，说明相应的基线、限制、验收、监控或回退安排。 | 补充相应安排 |
| PG-009 | 流程关系与前置条件（可选） | 存在“流程关系与前置条件”章节时：上级流程、前置条件和后续操作可理解且与流程相符。 | 修正或补充相关说明 |
| PG-010 | 全局验收条件（可选） | 存在“全局验收条件”章节时：条目说明整篇流程级通过要求。 | 补充条目 |
| PG-011 | 全局异常处置（可选） | 存在“全局异常处置”章节时：条目说明异常现象、处理或回退方向。 | 补充条目 |
| PG-012 | 案例列表 / 术语 / 接口文档列表（可选） | 存在相应章节时：每项仅保留名称和一句简述，且必须提供可跳转超链接；不以大段正文展开细节。 | 精简为名称 + 一句简述 + 链接 |
| PG-013 | 流程总览（可选） | 存在“流程总览”章节时：位于“操作步骤”之前，并包含流程图、mermaid 图或其他示意图。 | 调整位置或补充示意图 |
| PG-014 | 安全说明 / 产品形态与资源限制（可选） | 存在相应章节时：安全、产品形态或资源约束与流程实际风险、部署形态、依赖或容量相匹配。 | 修正内容 |
