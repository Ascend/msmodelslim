# 流程指南校验清单

> 用于校验基于《[流程指南模板](02_process_guide_template.md)》新建或整改的流程指南文档。通用校验条目见《[公共校验清单](00_common_checklist.md)》，校验机制（严重级别、结论规则、校验执行与豁免机制）见《[msModelSlim 资料规范](./README.md)》第4.2节；以下为流程指南类型专属校验条目，按严重级别分表。

## 1. 校验条目

### 1.1 ERROR（必须满足）

| 编号 | 校验条目 | 判定条件 | 处理建议 |
| :--- | :--- | :--- | :--- |
| PE-01 | 核心章节 | 文档存在“适用范围”、“输入和交付件”、“操作步骤”三个核心章节。 | 补齐缺失章节 |
| PE-02 | 输入与交付件 | “输入和交付件”章节同时包含至少一个输入项和至少一个交付件项。 | 补充输入项或交付件项 |
| PE-03 | 操作步骤 | “操作步骤”章节包含至少一个步骤，且每个步骤同时包含“操作”与“输出”。 | 补充步骤，或为步骤补充操作与输出 |

### 1.2 WARN（建议满足）

| 编号 | 校验条目 | 判定条件 | 处理建议 |
| :--- | :--- | :--- | :--- |
| PW-01 | 标题与范围 | 标题能表达流程主题；适用范围说明了适用对象、场景或边界。 | 调整标题或适用范围 |
| PW-02 | 输入与交付件 | 输入项与交付件项可定位，说明了必要的来源、约束或验收方式。 | 补充来源、约束或验收方式 |
| PW-03 | 步骤闭环 | 步骤顺序合理；已按需补充输入、执行前检查、通过条件、审计记录与异常处置。 | 补充步骤要素 |
| PW-04 | 命令与引用 | 命令、变量与路径有必要的说明；引用的能力有证据来源。 | 补充说明或证据来源 |
| PW-05 | 特殊场景 | 涉及精度、性能、安全、产品形态、资源、发布或运行时，已说明相应的基线、限制、验收、监控或回退安排。 | 补充相应安排 |
| PW-06 | 流程关系与前置条件 | 仅当“流程关系与前置条件”章节存在时校验：上级流程、前置条件与后续操作表述清楚，且与流程实际相符。 | 修正或补充相关说明 |
| PW-07 | 流程总览 | 仅当“流程总览”章节存在时校验：该章节位于“操作步骤”之前，且包含流程图、Mermaid 图或其他示意图。 | 调整章节位置或补充示意图 |
| PW-08 | 验收条件 | 仅当“验收条件”章节存在时校验：各条目说明了整篇流程层面的通过要求。 | 补充验收条目 |
| PW-09 | 异常处置 | 仅当“异常处置”章节存在时校验：各条目说明了异常现象与处理或回退方向。 | 补充异常处置条目 |
| PW-10 | 案例列表、术语与接口文档列表 | 仅当“案例列表”、“术语”或“接口文档列表”章节存在时校验：每项只保留名称与一句简述，并提供可跳转的超链接，不以大段正文展开细节。 | 精简为名称、一句简述与链接 |
| PW-11 | 安全说明 | 仅当“安全说明”章节存在时校验：安全说明与流程实际风险相匹配。 | 修正安全说明 |
| PW-12 | 产品形态与资源限制 | 仅当“产品形态与资源限制”章节存在时校验：产品形态、依赖与容量约束与流程实际相符。 | 修正产品形态与资源限制 |

## 2. 使用说明

- **校验范围**：基于《[流程指南模板](02_process_guide_template.md)》编写的流程指南与使用指南，包括业务流程指南与工具使用指南。
