# 量化配置文档校验清单

> 用于校验基于《[量化配置文档模板](04_quantization_config_document_template.md)》新建或整改的文档，适用于任务配置（含 `PracticeConfig`）、服务规格及其引用配置。通用校验条目与校验机制（使用说明 / 校验执行 / 豁免机制）见《[公共校验清单](00_common_checklist.md)》；以下为量化配置文档类型专属校验条目，按严重级别分表。

## 1. 校验条目

### 1.1 ERROR（必须满足）

| 编号 | 校验条目 | 判定条件 | 处理建议 |
| :--- | :--- | :--- | :--- |
| QE-01 | 配置概述元信息 | “配置概述”元信息表格包含配置类和源码链接，两者均可在目标版本源码中定位。 | 补齐缺失字段，修正失效链接 |
| QE-02 | 参数列表完整性 | “参数列表”按配置类名分块组织，覆盖配置类直接定义及通过继承对外开放的全部字段；字段路径为相对当前配置的字段名；嵌套配置（含任务配置的 spec）已展开为对应类名子块或通过“引用配置”列链接到独立文档。 | 补齐缺失块或字段，删除不存在字段，修正字段路径 |
| QE-03 | 字段属性一致 | 每个字段的类型、必选/可选状态、默认值与模型定义及运行时校验一致；枚举值、边界、格式约束描述完整。 | 修正不一致的字段属性 |
| QE-04 | 引用配置列 | 参数表“引用配置”列覆盖本配置使用的全部嵌套配置与 `type`/`mode` 分派目标，链接指向本页锚点或独立配置文档；分派字段统一指向基础类块锚点，派生类可由基础类块的“派生类”列表索引到子块或独立页；同一页面同一基础类只渲染一次。 | 补齐遗漏引用，修正链接目标，合并重复基础类块 |
| QE-05 | 完整配置参考 | 存在“完整配置参考”时，YAML 语法正确、配置放在实际的完整字段路径中、可被配置加载入口成功解析；无法提供可解析的完整示例时该章节可省略且不残留占位符。 | 修正 YAML 语法或路径层级，或删除不适用章节 |

### 1.2 WARN（建议满足）

| 编号 | 校验条目 | 判定条件 | 处理建议 |
| :--- | :--- | :--- | :--- |
| QW-01 | 配置概述内容 | “配置概述”明确说明控制的量化阶段、适用模型或场景，以及在完整配置中的位置。 | 补充或修正配置概述 |
| QW-02 | 配置约束子项 | 每个配置块的“配置约束”仅描述可由解析器、校验器或加载逻辑判断的规则（互斥、依赖、优先级、回退等）；没有额外约束时已明确填写“- 无。”。 | 移除无法校验的实践性约束（移至“注意事项”），或填写“- 无。” |
| QW-03 | 嵌套块类概述 | 展开的嵌套配置块在标题后、参数表前有一句该类概述（类 docstring 首段非空时）；无 docstring 时可省略。 | 补充类概述，或保持省略 |
| QW-04 | 示例值约束 | “完整配置参考”示例值满足参数约束，与参数列表一致；复杂嵌套配置通过 `type` 标明类型，未使用省略号代替。 | 修正不一致的示例值，展开省略部分 |
| QW-05 | 兼容性与迁移 | “兼容性与迁移”仅在存在版本差异时保留；废弃字段已说明替代方案和迁移方式。 | 删除不适用章节，或补充迁移说明 |
| QW-06 | 注意事项 | “注意事项”仅描述运行时实践问题（性能、精度、显存等），不重复各配置块“配置约束”中已有的校验规则。 | 将可校验规则移至对应配置块“配置约束”，保留实践问题 |
| QW-07 | 标题序号与锚点 | 文档标题已按模板顺序使用序号（1. 配置概述、2. 参数列表、3. 完整配置参考，可选 4. 兼容性与迁移、5. 注意事项）；参数列表各配置块标题带可见编号（如 `2.1 类名`、`2.x 派生类名`）；页内跳转使用 HTML 锚点 `<a href="#anchor">§x.y</a>`，未使用 Markdown 的 `{#anchor}` 语法。 | 补充或修正章节标题序号，统一锚点写法 |
