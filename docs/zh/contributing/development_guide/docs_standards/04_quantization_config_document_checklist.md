# 量化配置文档校验清单

> 用于校验基于[《量化配置文档模板》](04_quantization_config_document_template.md)新建或整改的文档，适用于 `ModelslimV1ServiceConfig`、`MultimodalSDServiceConfig`、`MultimodalVLMServiceConfig` 及其引用配置。通用校验条目与校验机制（使用说明 / 校验执行 / 豁免机制）见[《公共校验清单》](00_common_checklist.md)；以下为量化配置文档类型专属校验条目，按严重级别分表。

## 1. 校验条目

### 1.1 ERROR（必须满足）

| 编号 | 校验条目 | 判定条件 | 处理建议 |
| :--- | :--- | :--- | :--- |
| Q01 | 配置概述元信息 | “配置概述”元信息表格包含配置类和源码链接，两者均可在目标版本源码中定位。 | 补齐缺失字段，修正失效链接 |
| Q03 | 参数列表完整性 | “参数列表”覆盖配置类直接定义及通过继承对外开放的全部字段；字段使用从配置根节点开始的完整路径。 | 补齐缺失字段，删除不存在字段，修正路径 |
| Q04 | 字段属性一致 | 每个字段的类型、必选/可选状态、默认值与模型定义及运行时校验一致；枚举值、边界、格式约束描述完整。 | 修正不一致的字段属性 |
| Q06 | 引用的配置 | “引用的配置”覆盖本配置使用的全部嵌套配置，链接指向字段说明或独立配置文档；存在联合类型子配置时，已填写“适用字段”“子配置类别”“`type` 或辨识值”列；普通引用这三列填写“-”。子配置类型较多（超过5个）时，允许使用汇总行 + 子配置索引表的模式，汇总行的“`type` 或辨识值”填写“见下方索引”并链接到索引表。 | 补齐遗漏引用，修正链接目标，补充子配置列；子类型过多时改用索引表模式 |
| Q08 | 完整配置参考 | “完整配置参考”提供语法正确的 YAML，配置放在实际的完整字段路径中，可被配置加载入口成功解析。 | 修正 YAML 语法或路径层级 |

### 1.2 WARN（建议满足）

| 编号 | 校验条目 | 判定条件 | 处理建议 |
| :--- | :--- | :--- | :--- |
| Q02 | 配置概述内容 | “配置概述”明确说明控制的量化阶段、适用模型或场景，以及在完整配置中的位置。 | 补充或修正配置概述 |
| Q05 | 配置约束 | “配置约束”仅描述可由解析器、校验器或加载逻辑判断的规则（互斥、依赖、优先级、回退等）；没有额外约束时已明确填写“无”。 | 移除无法校验的实践性约束（移至“注意事项”），或填写“无” |
| Q07 | 被引用的配置 | “被引用的配置”覆盖所有已知上层入口，注明引用位置和适用场景；没有引用方时已用“无。”替代表格。 | 补充引用方信息，或填写“无。” |
| Q09 | 示例值约束 | “完整配置参考”示例值满足参数约束，与参数列表一致；复杂嵌套配置通过 `type` 标明类型，未使用省略号代替。 | 修正不一致的示例值，展开省略部分 |
| Q10 | 兼容性与迁移 | “兼容性与迁移”仅在存在版本差异时保留；废弃字段已说明替代方案和迁移方式。 | 删除不适用章节，或补充迁移说明 |
| Q11 | 注意事项 | “注意事项”仅描述运行时实践问题（性能、精度、显存等），不重复“配置约束”中已有的校验规则。 | 将可校验规则移至“配置约束”，保留实践问题 |
| Q12 | 标题序号 | 文档标题已按模板顺序使用序号（如 1. 配置概述、2. 参数列表、3. 配置约束 等）。 | 补充或修正章节标题序号 |
