# 通用案例校验清单

> 用于校验基于[《通用案例模板》](03_general_case_template.md)新建或整改的文档，并核对与关联流程指南的衔接关系。通用校验条目与校验机制（使用说明 / 校验执行 / 豁免机制）见[《公共校验清单》](00_common_checklist.md)；以下为通用案例类型专属校验条目，本清单条目均为 ERROR（必须满足）。

## 1. 校验条目

### 1.1 ERROR（必须满足）

| 编号 | 校验条目 | 判定条件 | 处理建议 |
| :--- | :--- | :--- | :--- |
| GC-001 | 文件命名与标题 | 文件名为 `{model_name}_{scenario_type}_case.md`，标题为 `{model_name}-{scenario_type}案例` 可读形式。 | 按约定重命名文件并调整标题 |
| GC-002 | 章节编号与结构 | 章节编号连续，结构与模板主线一致（背景 → 环境与版本 → 输入和交付件 → 操作步骤 → 结果与经验）。 | 调整章节编号与顺序 |
| GC-003 | 目标与使用场景 | 案例背景已说明本次目标与使用场景。 | 补充目标与场景 |
| GC-004 | 覆盖的流程步骤 | 案例背景已说明实际覆盖的流程步骤名称。 | 补充步骤名称 |
| GC-005 | 关联流程链接 | 已提供「关联流程」超链接，且链接可访问。 | 补充或修正链接 |
| GC-006 | 不重复规范 | 未在背景中重复流程级规范条文（规范见关联流程）。 | 精简背景，去重规范条文 |
| GC-007 | 实际依赖 | 环境与版本表已填写本次实际依赖，含「产品形态」项，非空泛描述。 | 补充实际依赖 |
| GC-008 | 产品形态 | 产品形态已写明并标明是否限定；限定时写明适用边界。 | 补充产品形态与边界 |
| GC-009 | 版本 | 版本项已给出版本号或文档/发布页链接。 | 补充版本号或链接 |
| GC-010 | 依赖项 | 依赖项按实际使用填写；多选一时仅保留实际使用项，未使用项已删除。 | 精简依赖项 |
| GC-011 | 前置事实 | 「本次前置事实」仅为案例开始前已满足的事实，非空泛或流程级条款。 | 修正前置事实 |
| GC-012 | 分项与表头 | 输入与交付件分项列出，表头含：类型、名称、来源或保存位置、格式或约束、验收方式。 | 补充表头与分项 |
| GC-013 | 来源可定位 | 每项来源或保存位置可定位（路径、链接或明确获取方式）。 | 补充来源 |
| GC-014 | 格式或约束 | 每项「格式或约束」已填写且可核对。 | 补充格式或约束 |
| GC-015 | 验收方式 | 每项具备可验证的验收方式；量化权重类交付件含 md5 或 safetensors 比对结果（或等价可核对方式）。 | 补充验收方式或比对结果 |
| GC-016 | 实际取值 | 填写的是本案例实际取值，而非未落地的占位说明或模板示例原文。 | 替换为实际取值 |
| GC-017 | 步骤完整性 | 已保留步骤均包含：目标、输入、操作、输出、记录、下一步。 | 补充步骤要素 |
| GC-018 | 操作可执行 | 操作具体可执行；关键命令或配置以代码块给出。 | 补充命令或代码块 |
| GC-019 | 输出可追溯 | 输出与记录可追溯（产物路径、日志或结果目录等）。 | 补充产物路径或日志 |
| GC-020 | 步骤顺序 | 步骤按执行顺序编排；未覆盖步骤已删除；与背景中声明覆盖的步骤一致。 | 调整顺序或删除步骤 |
| GC-021 | 不重复门禁 | 未重复关联流程中的执行前检查、通过条件、异常处置等通用门禁。 | 精简步骤 |
| GC-022 | 关键结果汇总 | 「关键结果汇总」表已填写关键步骤、操作、指标、变化与备注。 | 补充汇总表 |
| GC-023 | 事实数据 | 指标与变化为可核对的事实数据（或明确说明无法给出数值的原因）。 | 补充数据或说明原因 |
| GC-024 | 经验可迁移 | 「经验总结」为可迁移结论，而非操作步骤复述。 | 重写经验总结 |
| GC-025 | 适用边界 | 经验总结注明适用边界（数据、负载、版本、产品形态等）。 | 补充适用边界 |
| GC-026 | 异常处理（可选） | 若编写异常处理：内容为本次踩坑与排查/回退，而非通用门禁条文。 | 重写为本次踩坑内容 |
| GC-027 | 附录（可选） | 若编写附录：配置/脚本、Issue/PR、日志等材料可访问或可复现。 | 补充材料或链接 |
| GC-028 | 章节一致性 | 未选用的可选章节已删除；背景声明覆盖的步骤在正文均有对应。 | 删除未用章节或补充正文 |
| GC-029 | 关联流程存在 | 关联的流程文档存在，且案例场景落在该流程适用范围内。 | 修正关联或补充流程 |
| GC-030 | 交付件不冲突 | 案例交付件与关联流程要求的关键交付件不冲突。 | 调整交付件 |
| GC-031 | 入口链接 | 若流程「案例列表」需挂接本案例，入口链接已更新或已提跟踪项。 | 更新入口或登记跟踪项 |
| GC-032 | 路径泛化 | 路径已泛化或使用环境变量约定，他人可按说明复现。 | 泛化路径 |
| GC-033 | 结论一致 | 结论表述与「关键结果汇总」及交付件验收数据一致，未夸大未验证收益。 | 修正结论 |
