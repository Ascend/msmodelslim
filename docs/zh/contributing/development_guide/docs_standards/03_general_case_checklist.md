# 案例参考校验清单

> 用于校验基于《[案例参考模板](03_general_case_template.md)》新建或整改的案例参考文档，并核对与关联流程指南的衔接关系。通用校验条目见《[公共校验清单](00_common_checklist.md)》，校验机制（严重级别、结论规则、校验执行与豁免机制）见《[msModelSlim 资料规范](./README.md)》第4.2节；以下为案例参考类型专属校验条目，按严重级别分表。

## 1. 校验条目

### 1.1 ERROR（必须满足）

| 编号 | 校验条目 | 判定条件 | 处理建议 |
| :--- | :--- | :--- | :--- |
| GE-01 | 文件命名与标题 | 文件名为 `{model_name}_{scenario_type}_case.md`，标题为 `{model_name}-{scenario_type}案例` 的可读形式。 | 按约定重命名文件并调整标题 |
| GE-02 | 主线章节 | 存在“案例背景”、“环境与版本”、“输入和交付件”、“操作步骤”、“结果与经验”五个章节，且顺序与模板一致。 | 补齐缺失章节并调整顺序 |
| GE-03 | 覆盖步骤对应 | “案例背景”已列出实际覆盖的流程步骤名称，且这些步骤在“操作步骤”中均有对应；未覆盖的步骤已删除。 | 补齐缺失的步骤，或删除未覆盖的步骤 |
| GE-04 | 环境与版本 | 已填写本案例实际依赖，而非模板示例或空泛描述；含“产品形态”项并标明是否限定，各依赖项给出版本号或链接。 | 补充实际依赖、产品形态或版本信息 |
| GE-05 | 输入和交付件 | 分项列出，表头含类型、名称、来源或保存位置、格式或约束、验收方式；各列填写本案例实际取值，可定位、可核对。 | 补充表头或分项，将示例值替换为实际取值 |
| GE-06 | 操作步骤 | “操作步骤”包含至少一个步骤，每个保留的步骤均含“操作”与“输出”。 | 补充缺失的步骤，或为步骤补充操作与输出 |
| GE-07 | 关键结果汇总 | “关键结果汇总”表已填写关键步骤、操作、指标、变化与备注；指标与变化为可核对的事实数据，或已说明无法给出数值的原因。 | 补充汇总表，或补充数据与原因说明 |
| GE-08 | 关联流程链接 | 已提供指向关联流程指南的超链接。链接有效性由公共清单 CE-12 校验，本条只查有无。 | 补充关联流程链接 |

### 1.2 WARN（建议满足）

| 编号 | 校验条目 | 判定条件 | 处理建议 |
| :--- | :--- | :--- | :--- |
| GW-01 | 案例背景说明 | “案例背景”已说明本次目标与使用场景。 | 补充目标与场景 |
| GW-02 | 内容不重复 | 未在“案例背景”中重复流程级规范条文，未在“操作步骤”中重复关联流程的执行前检查、通过条件与异常处置等通用门禁。 | 精简背景与步骤，删除重复的规范条文与门禁 |
| GW-03 | 步骤质量 | 步骤按执行顺序编排；操作具体可执行，关键命令或配置以代码块给出；输出与记录可追溯；“下一步”若编写则指向后续步骤且与顺序一致。 | 调整步骤顺序，或补充命令、产物路径与记录 |
| GW-04 | 前置条件 | “本案例前置条件”仅为案例开始前需满足的条件，非流程级条款或空泛描述。 | 修正前置条件 |
| GW-05 | 流程衔接 | 案例场景落在关联流程的适用范围内；交付件与关联流程要求的关键交付件不冲突。 | 修正关联流程，或调整交付件 |
| GW-06 | 可复现性 | 案例可按文档说明复现，所需输入、命令与产物路径均可定位。 | 补充可复现所需的信息 |
| GW-07 | 结论一致 | 结论表述与“关键结果汇总”及交付件验收数据一致，未夸大未验证的收益。 | 修正结论 |
| GW-08 | 经验可迁移 | “经验总结”为可迁移的结论，并注明适用边界（数据、负载、版本、产品形态等），而非操作步骤复述。 | 重写经验总结并补充适用边界 |
| GW-09 | 异常处理 | 仅当“异常处理”章节存在时校验：内容为本次踩坑与排查、回退过程，而非通用门禁条文。 | 改写为本次踩坑内容 |
| GW-10 | 附录 | 仅当“附录”章节存在时校验：配置、脚本、Issue、PR、日志等材料可访问或可复现。 | 补充材料或链接 |
| GW-11 | 入口链接 | 若关联流程的“案例列表”需要收录本案例，入口链接已更新，或已在关联流程中登记待收录事项。 | 更新入口链接或登记待收录事项 |

## 2. 使用说明

- **校验范围**：基于《[案例参考模板](03_general_case_template.md)》编写的案例参考文档，存放于 `docs/zh/best_practices/`。
