# 配置文档校验清单

> 用于校验基于《[配置文档模板](04_config_document_template.md)》新建或整改的配置文档，适用于任务配置（含 `PracticeConfig`）、服务规格及其引用配置。通用校验条目见《[公共校验清单](00_common_checklist.md)》，校验机制（严重级别、结论规则、校验执行与豁免机制）见《[msModelSlim 资料规范](./README.md)》第4.2节；以下为配置文档类型专属校验条目，按严重级别分表。

## 1. 校验条目

### 1.1 ERROR（必须满足）

| 编号 | 校验条目 | 判定条件 | 处理建议 |
| :--- | :--- | :--- | :--- |
| FE-01 | 配置概述元信息 | “配置概述”的元信息表格包含配置类与源码链接，两者均可在目标版本的源码中定位。 | 补齐缺失字段，修正失效链接 |
| FE-02 | 参数列表完整与引用 | “参数列表”按配置类名分块，覆盖配置类直接定义及通过继承对外开放的全部字段；字段路径为相对当前配置的字段名；嵌套配置（含任务配置的 `spec`）已展开为对应类名子块，或通过“引用配置”列链接到独立文档；“引用配置”列覆盖本配置使用的全部嵌套配置与 `type`、`mode` 分派目标，链接指向本页锚点或独立配置文档；同一页面中同一基础类只渲染一次。 | 补齐缺失的块或字段，删除不存在的字段，修正字段路径与引用链接 |
| FE-03 | 字段属性一致 | 每个字段的类型、默认值、必选或可选状态，均与源码定义及运行时校验一致。 | 修正不一致的字段属性 |
| FE-04 | 完整配置参考 | 仅当“完整配置参考”章节存在时校验：YAML 语法正确，配置置于实际字段路径下，且可被配置加载入口成功解析。 | 修正 YAML 语法或路径层级 |

### 1.2 WARN（建议满足）

| 编号 | 校验条目 | 判定条件 | 处理建议 |
| :--- | :--- | :--- | :--- |
| FW-01 | 配置概述内容 | “配置概述”说明了该配置控制的量化阶段、适用模型或场景，以及它在完整配置中的位置。 | 补充或修正配置概述 |
| FW-02 | 参数描述完整 | 各字段的“取值范围或格式”包含枚举值、数值边界与路径格式；无法枚举时给出明确的约束说明。 | 补充取值范围或格式 |
| FW-03 | 约束与注意事项分工 | “配置约束”只描述可由解析器、校验器或加载逻辑判断的规则，包括互斥、依赖、优先级与回退，没有额外约束时已填写“- 无”；“注意事项”只描述运行时实践问题，包括性能、精度与显存等，不重复“配置约束”中已有的规则。 | 将无法校验的实践性约束移至“注意事项”，将可校验的规则移至对应配置块的“配置约束” |
| FW-04 | 完整配置参考 | 建议编写“完整配置参考”章节，提供置于实际字段路径下、可直接加载的完整 YAML 示例。 | 补充“完整配置参考”章节 |
| FW-05 | 示例值约束 | 仅当“完整配置参考”章节存在时校验：示例值满足参数约束，且与参数列表一致；复杂嵌套配置通过 `type` 标明类型，未使用省略号代替。 | 修正不一致的示例值，展开省略部分 |
| FW-06 | 兼容性与迁移 | 仅当“兼容性与迁移”章节存在时校验：废弃字段已说明替代方案与迁移方式。 | 补充替代方案与迁移方式 |
| FW-07 | 锚点写法 | 页内跳转使用 HTML 锚点 `<a href="#anchor">§x.y</a>`，未使用 Markdown 的 `{#anchor}` 语法。 | 统一为 HTML 锚点写法 |

## 2. 使用说明

- **校验范围**：基于《[配置文档模板](04_config_document_template.md)》编写的配置文档，存放于 `docs/zh/api_reference/config/`，其中由生成器产出的文档带 `generated-by` 标记，不手工编辑。
