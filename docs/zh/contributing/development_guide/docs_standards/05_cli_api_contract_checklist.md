# 命令行 API 文档校验清单

> 用于校验基于[《命令行 API 文档模板》](05_cli_api_contract_template.md)新建或整改的文档。通用校验条目与校验机制（使用说明 / 校验执行 / 豁免机制）见[《公共校验清单》](00_common_checklist.md)；以下为命令行 API 文档类型专属校验条目，按严重级别分表。

## 1. 校验条目

### 1.1 ERROR（必须满足）

| 编号 | 校验条目 | 判定条件 | 处理建议 |
| :--- | :--- | :--- | :--- |
| C01 | 命令名称一致 | 文档标题中的命令名称与实际可执行命令一致。 | 修正标题中的命令名称 |
| C02 | 功能说明 | “功能说明”已填写，准确描述命令的能力、适用场景和边界，非占位符或空。 | 补充或修正功能说明 |
| C03 | 命令格式 | “命令格式”给出完整的语法摘要，正确使用方括号（可选）和尖括号（需替换的值），未被表述为可直接复制的命令。 | 修正语法摘要，确保与 `--help` 一致 |
| C04 | 参数列表完整性 | “参数列表”覆盖 `--help` 和实现代码中对用户开放的全部参数，无遗漏或多余项。 | 补齐缺失参数，删除不存在或内部参数 |
| C05 | 参数属性一致 | 每个参数的名称、别名、类型、必选/可选状态、默认值与实现一致；布尔参数明确区分无值开关和显式值传入方式。 | 修正不一致的字段 |

### 1.2 WARN（建议满足）

| 编号 | 校验条目 | 判定条件 | 处理建议 |
| :--- | :--- | :--- | :--- |
| C06 | 参数关系 | “参数关系”已说明互斥、依赖、优先级等规则；没有参数关系时已明确填写“无”。 | 补充参数关系或填写“无” |
| C07 | 引用的配置 | “引用的配置”仅在命令通过参数加载 YAML 配置或量化方案时保留；链接指向配置文档而非仅指向源码。 | 删除不适用章节，或修正链接目标 |
| C08 | 环境变量 | “环境变量”仅在存在命令专属环境变量时保留；全局环境变量未重复说明；不包含真实凭据。 | 删除不适用章节，或移除敏感信息 |
| C09 | 使用示例 | “使用示例”存在时，第一条为最小可跑场景；示例使用大写 shell 变量代替具体值；不包含真实密钥或内部地址。 | 精简示例参数，替换敏感值为变量 |
| C10 | 退出码与异常处理 | “退出码与异常处理”保持轻量；未定义稳定退出码时仅说明 `0`/非 `0` 含义。 | 精简或补充退出码说明 |
| C11 | 破坏性变更 | 已识别相对上一稳定版本的破坏性变更（参数增删、默认值变化、行为变化等）。 | 在文档中补充变更说明 |
