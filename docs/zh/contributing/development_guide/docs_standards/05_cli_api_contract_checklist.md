# 命令行 API 文档校验清单

> 用于校验基于《[命令行 API 文档模板](05_cli_api_contract_template.md)》新建或整改的命令行接口文档。通用校验条目见《[公共校验清单](00_common_checklist.md)》，校验机制（严重级别、结论规则、校验执行与豁免机制）见《[msModelSlim 资料规范](./README.md)》第4.2节；以下为命令行 API 文档类型专属校验条目，按严重级别分表。

## 1. 校验条目

### 1.1 ERROR（必须满足）

| 编号 | 校验条目 | 判定条件 | 处理建议 |
| :--- | :--- | :--- | :--- |
| AE-01 | 命令名称一致 | 文档标题中的命令名称与实际可执行命令一致。 | 修正标题中的命令名称 |
| AE-02 | 命令格式 | “命令格式”给出完整语法摘要，必选参数直接列出、可选参数用方括号、需替换的值用尖括号标示，且未被表述为可直接复制的命令。 | 修正语法摘要，确保与 `--help` 一致 |
| AE-03 | 参数列表与实现一致 | “参数列表”覆盖 `--help` 与实现代码中对用户开放的全部参数，无遗漏或多余项；每个参数的名称、别名、类型、传入形式、默认值、必选或可选状态均与实现一致；布尔参数明确区分无值开关与显式传值两种用法。 | 补齐缺失参数，删除仅内部使用的参数，修正不一致的字段 |

### 1.2 WARN（建议满足）

| 编号 | 校验条目 | 判定条件 | 处理建议 |
| :--- | :--- | :--- | :--- |
| AW-01 | 功能说明 | “功能说明”准确描述命令的能力、适用场景与边界。 | 补充或修正功能说明 |
| AW-02 | 参数关系 | “参数关系”已说明互斥、依赖与优先级等规则；没有参数关系时已明确填写“无”。 | 补充参数关系，或填写“无” |
| AW-03 | 引用的配置 | 仅当“引用的配置”章节存在时校验：链接指向配置文档的字段说明或独立配置文档，而非只指向源码。 | 修正链接目标 |
| AW-04 | 环境变量 | 仅当“环境变量”章节存在时校验：默认值与代码一致；全局环境变量未重复说明。 | 修正默认值或删除重复说明 |
| AW-05 | 使用示例 | 仅当“使用示例”章节存在时校验：第一条为最小可运行场景；示例中的路径、模型名等使用大写 Shell 变量代替具体值。 | 精简示例参数，将具体值替换为变量 |
| AW-06 | 退出码与异常处理 | 仅当“退出码与异常处理”章节存在时校验：未定义稳定退出码时，只说明 `0` 与非 `0` 的含义，不罗列未定义的退出码。 | 精简为 `0` 与非 `0` 的说明 |
| AW-07 | 安全说明 | 仅当“安全说明”章节存在时校验：说明了风险、触发条件与规避措施。 | 补充风险、触发条件或规避措施 |

## 2. 使用说明

- **校验范围**：基于《[命令行 API 文档模板](05_cli_api_contract_template.md)》编写的命令行接口文档，存放于 `docs/zh/api_reference/cli/`。
