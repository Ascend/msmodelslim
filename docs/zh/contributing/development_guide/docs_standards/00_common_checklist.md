# 公共校验清单

> 适用于所有模板体系内文档。各类型校验清单引用本清单：通用校验条目与校验机制（使用说明 / 校验执行 / 豁免机制）在本清单统一定义，不在各类型清单重复。

## 1. 通用校验条目

### 1.1 ERROR（必须满足）

| 编号 | 校验条目 | 判定条件 | 处理建议 |
| :--- | :--- | :--- | :--- |
| CE-01 | 模板占位符 | 文件中不残留模板占位符 `{{ ... }}`。 | 将占位符替换为实际内容 |
| CE-02 | 模板注释 | 文件中不残留模板注释或模板自带的教学性章节（以 `> **注释：**` 开头、含“将 xxx 替换为”“必填”“选填”等指导性文字；或为仅指导文档编写、与发布内容无关的模板脚手架章节）。 | 删除模板注释或脚手架章节，或替换为正式说明 |
| CE-03 | 敏感信息 | 文档不包含密钥、令牌、内部地址、个人路径或其他敏感信息。 | 移除敏感信息，替换为占位说明 |
| CE-04 | 标题 | 文档存在且仅存在一个一级标题（H1），且与文档主题一致。 | 修正标题 |
| CE-05 | 书名号 | 文档正文引用其他文档标题时，标题以书名号《》括起（含链接引用：书名号内为锚文本链接，锚文本为目标文档正式标题、链接为相对路径，如 `《[XX 在 msModelSlim 中的完整实现](../../quantization_algorithms/xxx.md)》`）；正文中单独提及的文档标题亦使用书名号。 | 标题补加书名号 |
| CE-06 | 数字与单位间距 | 中文语境下数字与量词/单位之间不留空格，如 `≤5个`、`5类`、`80~200字`；不得写作 `≤ 5 个`、`5 类`。 | 删除数字与单位间空格 |

### 1.2 WARN（建议满足）

| 编号 | 校验条目 | 判定条件 | 处理建议 |
| :--- | :--- | :--- | :--- |
| CW-01 | 可选章节 | `[OPTIONAL]` 前缀仅用于模板定义的可选章节；发布文档时已删除不适用的可选章节及前缀，删除后章节按顺序重新编号、不留空号。 | 删除不适用的 `[OPTIONAL]` 章节，保留的章节去掉前缀并按序重排 |
| CW-02 | 渲染与链接 | Markdown 表格、标题层级、代码块语言标记和换行渲染正确；内联文档链接为相对路径且可解析。 | 修正格式错误或失效链接 |

## 2. 使用说明

- **编号**：通用条目以 `CE-`（ERROR）/ `CW-`（WARN）为前缀；各类型条目以类型前缀编号（见各类型校验清单）。
- **严重级别**：
  - `ERROR`：必须满足；任一不满足，结论为**不通过**。
  - `WARN`：建议满足；不满足时结论为**需修订**。
- **可选条目**：标题带 `[OPTIONAL]` 的章节不参与必填校验；未编写则不校验，编写后按对应条目校验。

## 3. 校验执行

- 触发时机：新增文档后全量校验；修改文档后增量校验（仅校验变更文件及受影响文件）。
- 执行者：校验可由人工评审或自动化 / AI 代理执行（AI 代理按校验清单逐项核对）。
- 结论规则：任一 ERROR 不满足 → **不通过**；仅 WARN 不满足 → **需修订**；全部满足 → **通过**。

## 4. 豁免机制

- 确有合理原因无法满足某条目时，在文档顶部声明 `<!-- waiver: 编号 原因：xxx -->`，校验时跳过该条目并记录原因；豁免不得用于规避 ERROR 条目超过2项，WARN 条目不设豁免数量限制。
