# 公共校验清单

> 本清单是《[msModelSlim 资料规范](./README.md)》的组成部分，列出适用于全部文档的通用校验条目，每条给出判定条件与处理建议。校验机制（严重级别、结论规则、校验执行与豁免机制）见《[msModelSlim 资料规范](./README.md)》第4.2节，条目编号规则与类型代码见[第7.1节](./README.md#71-校验清单编写约定)；各类型校验清单引用本清单中的通用条目，本清单不定义各类型专属条目。
> 适用范围：模板体系内文档须满足本清单全部条目；模板体系外文档（安装指南、快速入门、FAQ、版本说明等）至少满足 ERROR 条目。

## 1. 通用校验条目

### 1.1 ERROR（必须满足）

| 编号 | 校验条目 | 判定条件 | 处理建议 |
| :--- | :--- | :--- | :--- |
| CE-01 | 占位内容 | 文档中不残留模板占位符（如 `{{ 名称 }}`）与占位样例（如 `xxx`、`TODO`、`FIXME`、`待补充`、`TBD`）。 | 替换为实际内容 |
| CE-02 | 模板注释与脚手架 | 文档中不残留模板注释与模板脚手架章节。模板注释指指导编写者写作的注释，通常以 `> **注释：**` 开头，含“将 xxx 替换为”、“必填”、“选填”等提示文字，且不限于块引用形式；模板脚手架章节指仅用于指导编写、与发布内容无关的教学性章节。 | 删除模板注释与模板脚手架章节，或改写为面向读者的正式说明 |
| CE-03 | 敏感信息 | 文档不包含密钥、令牌、内部地址、个人路径或其他敏感信息。 | 移除敏感信息，替换为占位说明 |
| CE-04 | 标题结构 | 文档有且仅有一个一级标题，不含代码块内的示例标题；标题层级从二级标题起逐级递进，不跳级、层级连续。 | 修正标题或调整标题层级 |
| CE-05 | 书名号 | 引用其他文档标题时，标题用书名号《》括起；带链接的引用写作 `《[目标文档正式标题](相对路径)》`。 | 为文档标题补加书名号 |
| CE-06 | 数字与单位间距 | 中文语境下数字与量词、单位之间不留空格，例如写作 `≤5个`、`5类`、`80~200字`，不得写作 `≤ 5 个`、`5 类`。 | 删除数字与单位之间的空格 |
| CE-07 | 公式 | 公式采用 LaTeX 语法编写，行内公式用 `$...$`，块级公式用 `$$...$$`；不得用代码块标记包裹公式。块级公式下方以列表形式说明各变量的含义。 | 改用 LaTeX 语法，并补充公式变量的含义说明 |
| CE-08 | 图片 | 图片放入该文档同级的 `figures/` 目录并以相对路径引用。 | 将图片移至同级 `figures/` 目录，修正引用路径 |
| CE-09 | 标点符号 | 中文语境使用中文标点，不混用中英文标点；并列词语之间使用顿号，并列的引号或书名号之间也用顿号分隔，不得直接相连；引号、括号、书名号成对出现。 | 修正标点符号 |
| CE-10 | 可选章节 | 模板中以 `[OPTIONAL]` 标记的章节，发布时不适用的已整节删除；保留的已去掉 `[OPTIONAL]` 前缀，并已按顺序重新编号、不留空号。 | 删除不适用的 `[OPTIONAL]` 章节，保留的去掉前缀并按序重排 |
| CE-11 | Markdown 结构 | Markdown 表格列数与表头一致；代码块标注语言。 | 补齐表格单元格或表头，为代码块标注语言 |
| CE-12 | 文档链接 | 内联文档链接为相对路径，且可解析到仓库内实际存在的文件。 | 修正失效链接，改为可解析的相对路径 |
| CE-13 | 标题编号 | 一级标题不带序号；二级及以下标题带可见序号，同级序号连续，且序号与标题层级对齐（`x` 对应 `##`、`x.x` 对应 `###`、`x.x.x` 对应 `####`）。以 HTML 标题承载页内锚点时同样适用。 | 为标题补加序号，或修正序号与层级 |

### 1.2 WARN（建议满足）

| 编号 | 校验条目 | 判定条件 | 处理建议 |
| :--- | :--- | :--- | :--- |
| CW-01 | 语言与句式 | 文档使用面向用户的中文技术文档语体；约定俗成的通用缩写（如 AI、API、FAQ、CLI、SIG 等）可直接使用，其他缩写在第一次出现时先写出完整名称；句子成分完整，含义明确，不产生歧义。 | 调整语体，为非常用缩写补全全称，改写成分不完整或含义不明的句子 |
| CW-02 | 术语一致 | 同一概念在全文中使用同一名称，不与其他含义混用。 | 统一同一概念的名称，消除混用 |
| CW-03 | 标题可读性 | 标题能体现文档主题；标题层级建议不超过四级。 | 调整标题措辞或层级深度 |
| CW-04 | 图片显示尺寸 | 图片引用通过 HTML `<img>` 标签的 `width` 属性指定显示尺寸，避免图片过大影响阅读。 | 为过大的图片指定显示尺寸 |
| CW-05 | 渲染效果 | 换行与缩进在渲染后符合预期。 | 调整换行或缩进 |
| CW-06 | 命令与路径泛化 | 代码块中的命令与路径使用环境变量泛化，不写死具体路径；系统路径与固定安装位置除外。 | 将命令与路径中的具体值替换为环境变量 |
| CW-07 | 外部链接 | 外部链接使用 HTTPS 协议。 | 替换为 HTTPS 链接 |
