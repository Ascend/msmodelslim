> **注释：**
> 本文件是「量化术语百科」的**词条模板**，用于指导 agent 在 msModelSlim 知识库中新增/补全术语百科词条。
> 使用约定如下：
> - `{{ content }}`：需要填充的内容，`content` 为英文，多词以下划线连接。
> - `[OPTIONAL]`：前缀标签，表示该章节按需编写，无内容可省略整个章节。
> - 模板内说明以 `> **注释：**` 形式标注，正式词条中应删除该注释。
>
> - 术语百科以"陈述性知识"为主，区别于算法说明书（过程性知识）；本模板强调**知识原理**与**知识图谱（关联词条超链接）**。
> - **模板灵活性说明**：本模板提供了一个推荐的词条结构，但并非强制严格遵循。某些章节可根据术语的实际情况省略（如 QAT 没有 msModelSlim 实现，则整个"在 msModelSlim 中的实现"章节可整体省略）。具体哪些章节可省略，请参考文末"章节必要性一览"表中的"可选"标记。词条编写应以"讲清楚术语本身"为首要目标，不必为了对齐模板结构而填充无关内容。
> - **AI低错检查**：填写词条内容后，须按[《量化术语百科校验清单》](01_quantization_glossary_checklist.md)的 ERROR 条目逐项检查低错，包括但不限于错别字、中英文空格、标点全半角统一、语句通顺度、术语一致性等。生成词条后建议先做一遍低错自查再提交。
