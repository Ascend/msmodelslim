# 术语词条校验清单

> 用于校验基于《[术语词条模板](01_term_glossary_template.md)》新建或整改的术语词条文档。通用校验条目与校验机制（使用说明 / 校验执行 / 豁免机制）见《[公共校验清单](00_common_checklist.md)》；以下为术语词条类型专属校验条目，按严重级别分表。

## 1. 校验条目

### 1.1 ERROR（必须满足）

| 编号 | 校验条目 | 判定条件 | 处理建议 |
| :--- | :--- | :--- | :--- |
| TE-01 | 文件命名 | 文件命名为 `term_<english_name>.md`，`english_name` 为全小写英文，多词以下划线连接。 | 重命名文件 |
| TE-02 | 文件编码 | 文件以 UTF-8（建议带 BOM，与现有量化算法文档保持一致）编码。 | 转换编码 |
| TE-03 | 必填章节 | 必填章节不缺失：一级标题、顶部信息框、`## 概述`、`## 原理`（含 `### 核心思想`、`### 数学描述`、`### 关键性质`）、`## 适用场景与限制`（含 `### 适用场景`、`### 使用限制`）、`## 关联流程`、`## 关联词条`、`## 参考资料`。 | 补齐缺失章节 |
| TE-04 | 章节顺序 | 章节顺序与模板“章节必要性一览”一致。 | 调整章节顺序 |
| TE-05 | 顶部信息框字段 | 顶部信息框至少包含 `词条类别`、`英文名称`、`应用领域` 三项。 | 补充字段 |
| TE-06 | 词条类别取值 | 顶部信息框 `词条类别` 取值在模板允许的枚举集合内（量化基础概念 / 量化算法 / 离群值抑制算法 / 敏感层分析算法 / 自动调优策略 / 量化数据格式 / 量化参数 / 量化配置项 / 量化工具接口 / 量化评估指标 / 其他）。 | 修正取值 |
| TE-07 | 关键性质条目数 | `### 关键性质` 至少包含3条列表项。 | 补充性质 |
| TE-08 | 适用场景与使用限制条目数 | `### 适用场景` 至少包含2条；`### 使用限制` 至少包含2条。 | 补充内容 |
| TE-09 | 实现章节的条件出现 | `## [OPTIONAL] 在 msModelSlim 中的实现` 为“有条件出现”章节：仅当术语在 msModelSlim 代码库中有直接实现时写入；若整体省略，其下三个子章节全部省略；若出现任一子章节，则 `### 实现位置` 必填。 | 补齐或整体省略，禁止无实现时保留空章节 |
| TE-10 | 二级标题分隔符 | 除一级标题外，每一个二级标题（`## xxx`）出现前有一行 `---` 水平分隔符（含顶部信息框与首个二级标题之间、所有二级标题之间）；三级标题（`###`）前不插入 `---`。 | 补充或移除 `---` |
| TE-11 | 子标题编号 | 同一二级章节下多个并列三级标题（`###`）使用阿拉伯数字连续编号 `### 1. xxx`、`### 2. xxx`；四级标题（`####`）使用“父级编号.子序号”形式 `#### 2.1 xxx`，编号连续递增、不跳号不重复；仅一个三级标题时可省略编号。 | 补充/修正编号 |
| TE-12 | 关联词条链接形式 | `## 关联词条` 中每一项为 markdown 超链接形式：同领域用 `《[词条名](./term_xxx.md)》`，跨领域用相对路径 `《[词条名](../其他领域目录/term_xxx.md)》`，不允许纯文本词条名。 | 改为超链接 |
| TE-13 | 关联词条数量 | `## 关联词条` 至少包含3条关联词条。 | 补充关联词条 |
| TE-14 | 关系类型标注 | `## 关联词条` 每一项显式标注关系类型（上位概念 / 下位概念 / 同类算法 / 对比算法 / 前置术语 / 后续术语 / 配套术语 / 应用对象 / 评估指标 / 其他）。 | 补充关系类型 |
| TE-15 | 概述超链接 | `## 概述` 正文中提及的、已存在或将存在的术语词条，至少1处以超链接形式 `《[词条名](./term_xxx.md)》` 出现。 | 补充超链接 |
| TE-16 | 关联流程非空 | `## 关联流程` 不可为空；若无关联流程，显式写“暂无关联流程”。 | 补充内容或占位文字 |
| TE-17 | 链接路径可解析 | 所有 markdown 链接的相对路径能在仓库内解析（含跨领域相对路径；不允许指向仓库外绝对路径或外网 URL，参考资料除外）。 | 修正路径 |
| TE-18 | 概述非空 | `## 概述` 不为空，建议字数80~200字。 | 补充概述 |
| TE-19 | 概述三要素 | `## 概述` 回答三个问题：是什么 / 解决什么问题 / 核心特征。 | 重写概述 |
| TE-20 | 数学描述非空 | `### 数学描述` 不为空；非算法类术语可用形式化定义替代公式。 | 补充公式或形式化定义 |
| TE-21 | 公式语法 | 数学公式使用 LaTeX 语法：行内公式用 `$...$`，块级公式用 `$$...$$`；禁止使用反引号代码块标记包裹公式（包括正文中的公式引用）。 | 替换为 LaTeX 语法 |
| TE-22 | 变量说明 | 块级公式下方列出公式中所有变量的含义说明。 | 补充变量说明 |
| TE-23 | 参考资料数量 | `## 参考资料` 至少包含1条参考资料。 | 补充参考资料 |
| TE-24 | 知识类型 | 词条内容不直接复制算法说明书的完整章节；术语百科侧重“陈述性知识”（原理/性质/关联），算法说明书侧重“过程性知识”（步骤/配置/FAQ）。 | 重写为陈述性表述 |
| TE-25 | 占位残留 | 文档不含占位样例（如 `xxx`、`TODO`、`FIXME`、`待补充`、`TBD`）。 | 补充实际内容 |
| TE-26 | mermaid 顶层 | mermaid 代码块不被 HTML 标签（如 `<div align="center">`）包裹；mermaid 位于 markdown 顶层。 | 移除包裹的 HTML 标签 |
| TE-27 | 核心思想不重复 | `### 核心思想` 不与 `## 概述` 文本高度重复（相似度阈值 0.6）。 | 重写核心思想 |
| TE-28 | 变量定义 | 数学公式中所有变量在公式下方列表中说明，禁止“未定义变量”。 | 补充变量说明 |
| TE-29 | 符号一致 | 公式中变量符号在公式与说明列表中一致（大小写、下标）。 | 统一符号 |
| TE-30 | 链接一致性 | `## 关联词条` 中每个链接目标与显示文本指向同一术语（避免“显示 A 链接到 B”）。 | 修正锚文本或链接 |
| TE-31 | 外链可信 | `## 参考资料` 中外部链接为 HTTPS，且为 arXiv、官方会议/期刊、msModelSlim 仓库内文档之一。 | 替换为可信链接 |
| TE-32 | 内链相对路径 | `## 参考资料` 中的仓库内文档链接使用相对路径，且文件存在。 | 修正路径 |
| TE-33 | 待建词条登记 | `## 关联词条` 中的所有链接目标在未来词条扩充后必须存在；当前阶段若目标缺失，须在词条文件顶部 TODO 列表登记。本条目优先级高于 TW-05：只要目标词条已登记 TODO，即可通过本项校验，TW-05 的 WARN 可同步豁免。 | 登记待建词条 |
| TE-34 | 词条唯一性 | 同一术语不在 `docs/zh/knowledge_base/` 同一领域目录下存在多个词条文件（同名/同 `english_name`）。 | 合并或重命名 |

### 1.2 WARN（建议满足）

| 编号 | 校验条目 | 判定条件 | 处理建议 |
| :--- | :--- | :--- | :--- |
| TW-01 | 一级标题 | 文件首行为一级标题 `# <词条名>`，与文件名中 `english_name` 对应的中文名保持一致。 | 调整标题 |
| TW-02 | 缩进 | 文件不使用 Tab 缩进（统一使用空格）。 | 替换为空格 |
| TW-03 | 目录 | 词条文件不包含目录（模板中已移除目录）。 | 删除目录相关文本 |
| TW-04 | 英文名称一致性 | 顶部信息框 `英文名称` 与文件名 `term_<english_name>.md` 中的 `english_name` 一致（大小写可不一致，拼写一致）。 | 统一命名 |
| TW-05 | 链接目标存在性 | `## 关联词条` 与 `## 关联流程` 中所有 `./term_xxx.md` 链接指向实际存在的同目录词条文件。若目标词条尚在规划中（已在文件顶部 TODO 列表登记），可豁免本项检查，由 TE-33 作为唯一 ERROR 级的存在性校验。 | 修正链接或补齐被引用词条；若已登记 TODO 则豁免 |
| TW-06 | 关联流程链接 | `## 关联流程` 中每一项为 markdown 超链接，并指向 `docs/zh/` 下实际存在的流程指南文档。 | 修正链接 |
| TW-07 | 正文术语链接 | 正文中提及的术语名（如 SmoothQuant、GPTQ、per_token 等），若该术语已有或将有独立词条，使用超链接而非纯文本。 | 改为超链接 |
| TW-08 | 锚文本 | 超链接显示文本与目标词条的一级标题一致，避免“点此”“详见”等无信息量锚文本。 | 改用词条名作为锚文本 |
| TW-09 | 参考资料字段 | 学术参考资料包含：标题、作者、会议/期刊、年份、链接（arXiv 或官方）。 | 补全字段 |
| TW-10 | 图片路径 | 图片（若有）放在词条同级的 `figures/` 子目录下，并使用相对路径引用。 | 移动图片并修正路径 |
| TW-11 | 代码块语言 | 代码块标注语言（如 ` ```yaml `、` ```python `、` ```text `），不使用裸代码块。 | 补充语言标注 |
| TW-12 | 实现章节科普性 | `## 在 msModelSlim 中的实现` 章节保持科普性，避免罗列过多代码模块详细路径；完整的代码架构解析与模块调用链路通过超链接引用到算法说明文档。 | 精简路径列表，补充超链接引导 |
| TW-13 | 首次提出出处 | 顶部信息框 `首次提出` 字段有明确出处（作者、会议/期刊、年份），不填写“msModelSlim 自研算法”等无来源信息；无明确出处则删除该行。 | 删除该行或补充真实出处 |
| TW-14 | 配置示例注释 | `### 配置示例` 中的 YAML 不含逐行注释说明参数含义；详细参数说明通过引用块超链接引导至算法说明文档。 | 移除注释，补充超链接引导 |
| TW-15 | 推导步骤 | 多步推导使用编号公式，避免跳跃。 | 增加推导步骤 |
| TW-16 | 数学性质 | 若术语涉及对称性/等价变换/可逆性等数学性质，在 `### 关键性质` 中显式列出。 | 补充性质条目 |
| TW-17 | 关系类型多样 | 关联词条覆盖至少2种关系类型（如同时包含“上位概念”与“配套术语”），避免关系单一。 | 补充异构关系词条 |
| TW-18 | 论文置首 | 若术语源自学术论文，`## 参考资料` 第1条为该论文。 | 调整参考资料顺序 |
| TW-19 | 关联流程说明 | `## 关联流程` 中至少1项说明关系（如“使用本算法作为前置处理”），而非仅列链接。 | 补充关系说明 |
| TW-20 | 反向引用 | 每个词条至少被其他1个词条在 `## 关联词条` 中引用（入度 ≥1）。 | 补充反向引用 |
| TW-21 | 弱连通图 | 术语百科整体构成弱连通图（任一词条可经关联词条链接到达另一词条）。 | 补充跨簇关联词条 |

## 2. 类型使用说明

- **编号**：术语词条条目以 `TE-`（ERROR）/ `TW-`（WARN）为前缀，按严重级别分表连续编号，不再按内容类别（G/S/L/C/P/R/K）细分；通用条目见《[公共校验清单](./00_common_checklist.md)》CE/CW。
- **校验范围**：`docs/zh/knowledge_base/` 各领域（子）目录下的 `term_*.md` 术语词条（词条就近放在所属领域目录）。
- **修复优先级**：ERROR 条目优先于 WARN 条目（任一 ERROR 未解决即不通过）。
