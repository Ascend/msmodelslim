# 术语词条校验清单

> 用于校验基于《[术语词条模板](01_term_glossary_template.md)》新建或整改的术语词条文档。通用校验条目见《[公共校验清单](00_common_checklist.md)》，校验机制（严重级别、结论规则、校验执行与豁免机制）见《[msModelSlim 资料规范](./README.md)》第4.2节；以下为术语词条类型专属校验条目，按严重级别分表。

## 1. 校验条目

### 1.1 ERROR（必须满足）

| 编号 | 校验条目 | 判定条件 | 处理建议 |
| :--- | :--- | :--- | :--- |
| TE-01 | 文件命名 | 普通词条命名为 `term_<英文名>.md`，其中英文名为全小写英文，多个单词用下划线连接；类别词条与索引文档命名为 `README.md`。 | 按约定重命名文件 |
| TE-02 | 必填章节 | 一级标题、顶部信息框、`## 1. 概述`、`## 2. 词条介绍` 四项齐全，且顺序与模板一致。 | 补齐缺失章节并调整顺序 |
| TE-03 | 顶部信息框字段 | 顶部信息框至少包含“词条类别”与“英文名称”两项。 | 补充缺失字段 |
| TE-04 | 关联词条条目形式 | 仅当“关联词条”章节存在时校验：每一项为 Markdown 超链接，锚文本与目标词条名一致，并标注关系类型。 | 改为超链接、统一锚文本并补充关系类型 |
| TE-05 | 概述非空 | `## 1. 概述` 已填写，不为空。 | 补充概述 |
| TE-06 | 待建词条登记 | 仅当“关联词条”章节存在时校验：链接到尚未创建的词条时，已在词条文件顶部 TODO 列表登记。 | 在词条文件顶部登记待建词条 |
| TE-07 | 词条唯一性 | 同一术语在同一领域目录下只有一个词条文件，即文件不同名、英文名不重复。 | 合并或重命名词条文件 |

### 1.2 WARN（建议满足）

| 编号 | 校验条目 | 判定条件 | 处理建议 |
| :--- | :--- | :--- | :--- |
| TW-01 | 一级标题 | 文件首行的一级标题与词条名对应，不追加“术语词条”等后缀。 | 调整一级标题 |
| TW-02 | 英文名称一致 | 顶部信息框的“英文名称”与文件名中的英文名拼写一致，大小写可不一致。 | 统一两处英文名称 |
| TW-03 | 词条类别取值 | “词条类别”取值在模板允许的枚举集合内；非顶层词条填写上层词条链接。 | 修正取值或补填上层词条链接 |
| TW-04 | 标题分隔符 | 相邻二级标题之间有一行 `---` 分隔符，三级、四级标题前不加。 | 补充或移除 `---` 分隔符 |
| TW-05 | 关联流程链接 | 仅当“关联流程”章节存在时校验：每一项为超链接，指向实际存在的流程指南，且至少一项说明了与流程的关系。 | 修正链接并补充关系说明 |
| TW-06 | 术语超链接 | 概述与正文中提及的术语，凡已有或将有独立词条，均以超链接呈现而非纯文本。 | 改为超链接 |
| TW-07 | 概述三要素 | `## 1. 概述` 回答了三个问题，即这个概念是什么、解决什么问题、核心特征是什么。 | 重写概述 |
| TW-08 | 参考文档字段 | 仅当“参考文档”章节存在时校验：学术参考文档包含标题、作者、会议或期刊、年份与链接。 | 补全参考文档字段 |
| TW-09 | 参考文档顺序 | 仅当“参考文档”章节存在时校验：首条为权威来源。算法类词条首条为原始论文，数据格式类词条首条为对应标准文档（如 IEEE 754、OCP MX 规范）。 | 调整参考文档顺序，将权威来源置于首条 |
| TW-10 | 首次提出出处 | 顶部信息框中的“首次提出”字段有明确出处，即作者、会议或期刊与年份；无明确出处时不填写“msModelSlim 自研算法”等无来源信息。 | 补充真实出处，或删除该行 |
| TW-11 | 外链来源 | 仅当“参考文档”章节存在时校验：外部链接属于值得引用的来源，即 arXiv、官方会议或期刊、msModelSlim 仓库内文档之一。 | 替换为权威来源链接 |
| TW-12 | 反向引用 | 每个词条至少被其他一个词条在“关联词条”章节中引用，即入度不小于 1。 | 补充反向引用 |
| TW-13 | 弱连通图 | 术语词条整体构成弱连通图，即从任一词条出发可经关联词条链接到达其他任一词条。 | 补充跨簇关联词条 |

## 2. 使用说明

- **校验范围**：[`docs/zh/knowledge_base/`](../../../knowledge_base/README.md) 各领域及其子目录下的 `term_*.md` 术语词条，词条就近放在所属领域目录。仓库按“领域、类别、词条”三层组织词条文档：词条文档包括 `term_*.md` 与量化格式的 `<格式名>.md`，按本清单校验；类别词条与索引文档为 `README.md`，不要求 `term_*` 命名，仅校验其结构，且不参与 TW-12 与 TW-13 的入度与连通性统计。
- **对 CE-12 的补充**：链接到尚未创建、但已在词条文件顶部 TODO 列表登记的待建词条，属“已规划”，公共清单 CE-12 校验时不计为断链；未登记则计为 CE-12 失败，提示登记或修正链接。登记要求见 TE-06。
