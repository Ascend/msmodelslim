# 量化术语百科校验清单

> 用于校验基于[《量化术语百科词条模板》](01_term_glossary_template.md)新建或整改的术语百科文档。通用校验条目与校验机制（使用说明 / 校验执行 / 豁免机制）见[《公共校验清单》](00_common_checklist.md)；以下为术语百科类型专属校验条目，按严重级别分表。

## 1. 校验条目

### 1.1 ERROR（必须满足）

| 编号 | 校验条目 | 判定条件 | 处理建议 |
| :--- | :--- | :--- | :--- |
| G01 | 文件命名 | 明确区分三类文档的命名与校验规则：普通词条命名为 `term_<english_name>.md`（`english_name` 为全小写英文，多词以下划线连接）。类别/索引文档命名为 `README.md`，不强制 `term_*` 前缀，仅作结构性校验。 | 按类型重命名文件 |
| S01 | 必填章节 | 通用必填章节不缺失：一级标题、顶部信息框、`## 1. 概述`、`## 2. 词条介绍`。 | 补齐缺失章节 |
| S03 | 章节顺序 | 普通词条章节顺序与模板保持一致；量化格式词条、索引/类别类文档可依自身结构组织，不强制套用模板顺序，具体见模板"模板灵活性说明"。 | 调整章节顺序 |
| S05 | 顶部信息框字段 | 顶部信息框至少包含 `词条类别`、`英文名称` 两项，不做过多额外要求。 | 补充字段 |
| S06 | 词条类别取值 | 顶部信息框 `词条类别` 取值在模板允许的枚举集合内（量化基础概念 / 量化算法 / 离群值抑制算法 / 敏感层分析算法 / 自动调优策略 / 量化数据格式 / 量化参数 / 量化配置项 / 量化工具接口 / 量化评估指标 / 其他），且应填写上层词条链接（顶层词条可以不填）。 | 修正取值 |
| S11 | 二级标题分隔符 | 除一级标题外，每一个二级标题（`## xxx`）出现前有一行 `---` 水平分隔符（含顶部信息框与首个二级标题之间、所有二级标题之间）；三级标题（`###`）前不插入 `---`。量化格式词条不强制 H2 前分隔符。 | 补充或移除 `---` |
| L01 | 关联词条链接形式 | 仅当 `## 4. [OPTIONAL] 关联词条` 存在时校验：每一项为 markdown 超链接形式：同领域词条用 `[词条名](./term_xxx.md)`，跨领域用相对路径 `[词条名](../其他领域目录/term_xxx.md)`；格式图谱可链接格式词条文件、类别/索引文档或领域目录，不允许纯文本词条名。锚文本用词条名不加《书名号》（见 L10）。 | 改为超链接 |
| L02 | 关联词条数量 | 仅当 `## 4. [OPTIONAL] 关联词条` 存在时校验：关联词条数量结合实际分析，在覆盖必要关联关系基础上尽量丰富。 | 结合词条知识广度补充关联词条 |
| L03 | 关系类型标注 | 仅当 `## 4. [OPTIONAL] 关联词条` 存在时校验：每一项显式标注关系类型（上位概念 / 下位概念 / 同类算法 / 对比算法 / 前置术语 / 后续术语 / 配套术语 / 应用对象 / 评估指标 / 其他）。 | 补充关系类型 |
| L05 | 概述超链接 | `## 1. 概述` 正文中提及的、已存在或将存在的术语百科词条，均以超链接形式 `[词条名](./term_xxx.md)` 出现，数量结合实际分析、越多越好（格式词条可链接其格式词条文件或类别/索引文档）。 | 补充超链接 |
| C01 | 概述非空 | `## 1. 概述` 不为空，建议字数80~200字。 | 补充概述 |
| C02 | 概述三要素 | `## 1. 概述` 回答三个问题：是什么 / 解决什么问题 / 核心特征。 | 重写概述 |
| C08 | 知识类型 | 词条内容不直接复制算法说明书的完整章节；术语百科侧重"陈述性知识"（原理/性质/关联），算法说明书侧重"过程性知识"（步骤/配置/FAQ）。 | 重写为陈述性表述 |
| C10 | 占位残留 | 文档不含占位样例（如 `xxx`、`TODO`、`FIXME`、`待补充`、`TBD`）。 | 补充实际内容 |
| R01 | 链接一致性 | 仅当 `## 4. [OPTIONAL] 关联词条` 存在时校验：每个链接目标与显示文本指向同一术语（避免"显示 A 链接到 B"）。 | 修正锚文本或链接 |
| K02 | 待建词条登记 | 仅当 `## 4. [OPTIONAL] 关联词条` 存在时校验：所有链接目标在未来词条扩充后必须存在；当前阶段若目标缺失，须在词条文件顶部 TODO 列表登记。 | 登记待建词条 |
| K04 | 词条唯一性 | 同一术语不在 `docs/zh/knowledge_base/` 同一领域目录下存在多个词条文件（同名/同 `english_name`）。 | 合并或重命名 |

### 1.2 WARN（建议满足）

| 编号 | 校验条目 | 判定条件 | 处理建议 |
| :--- | :--- | :--- | :--- |
| G02 | 文件编码 | 文件以 UTF-8 编码（建议带 BOM，与现有量化算法文档保持一致）。 | 转换编码 |
| G05 | 一级标题 | 文件首行为一级标题 `# <词条名>`，与文件名中 `english_name` 对应的中文名保持一致。 | 调整标题 |
| G07 | 缩进 | 文件不使用 Tab 缩进（统一使用空格）。 | 替换为空格 |
| S04 | 目录 | 词条文件不包含目录（模板中已移除目录）。 | 删除目录相关文本 |
| S07 | 英文名称一致性 | 顶部信息框 `英文名称` 与文件名 `term_<english_name>.md` 中的 `english_name` 一致（大小写可不一致，拼写一致）。 | 统一命名 |
| L04 | 链接目标存在性 | 仅当 `## 4. [OPTIONAL] 关联词条` 存在时校验：所有 `./term_xxx.md` 链接指向实际存在的同目录词条文件。若目标词条尚在规划中（已在文件顶部 TODO 列表登记），可豁免本项检查，由 K02 作为唯一 ERROR 级的存在性校验。 | 修正链接或补齐被引用词条；若已登记 TODO 则豁免 |
| L06 | 关联流程链接 | 仅当 `## 3. [OPTIONAL] 关联流程` 存在时校验：每一项为 markdown 超链接，并指向 `docs/zh/` 下实际存在的流程指南文档。 | 修正链接 |
| L08 | 正文术语链接 | 正文中提及的术语名（如 SmoothQuant、GPTQ、per_token 等），若该术语已有或将有独立词条，使用超链接而非纯文本。 | 改为超链接 |
| L10 | 锚文本 | 链接锚文本用词条名，与目标词条一级标题一致（一级标题不含《，故链接锚文本不加《书名号》），避免"点此""详见"等无信息量锚文本；正文单独提及文档标题时才按《公共校验清单》CE-05 加《书名号》。 | 改用词条名作为锚文本 |
| C04 | 公式语法 | 存在公式时校验：数学公式使用 LaTeX 语法，行内公式用 `$...$`，块级公式用 `$$...$$`；禁止使用反引号代码块标记包裹公式（包括正文中的公式引用），避免公式字体与正文割裂。 | 替换为 LaTeX 语法 |
| C05 | 变量说明 | 存在块级公式时校验：块级公式下方列出公式中所有变量的含义说明。 | 补充变量说明 |
| C06 | 参考文档数量 | 仅当 `## 5. [OPTIONAL] 参考文档` 存在时校验：参考文档数量结合实际分析、越多越好，优先覆盖原始出处、工具内实现与延伸阅读。 | 补充参考文档 |
| C07 | 参考文档字段 | 仅当 `## 5. [OPTIONAL] 参考文档` 存在时校验：学术参考文档包含标题、作者、会议/期刊、年份、链接（arXiv 或官方）。 | 补全字段 |
| C12 | 代码块语言 | 代码块标注语言（如 ` ```yaml `、` ```python `、` ```text `），不使用裸代码块。 | 补充语言标注 |
| C16 | 首次提出出处 | 顶部信息框 `首次提出` 字段有明确出处（作者、会议/期刊、年份），不填写"msModelSlim 自研算法"等无来源信息；无明确出处则删除该行。 | 删除该行或补充真实出处 |
| R02 | 关系类型多样 | 仅当 `## 4. [OPTIONAL] 关联词条` 存在时校验：覆盖的关系类型结合实际分析、越多样越好（如同时包含"上位概念"与"配套术语"），避免关系单一。 | 补充异构关系词条 |

| R04 | 论文置首 | 仅当 `## 5. [OPTIONAL] 参考文档` 存在且术语源自学术论文时校验：第1条为该论文。 | 调整参考文档顺序 |
| R06 | 关联流程说明 | 仅当 `## 3. [OPTIONAL] 关联流程` 存在时校验：至少1项说明关系（如"使用本算法作为前置处理"），而非仅列链接。 | 补充关系说明 |
| K01 | 反向引用 | 每个词条至少被其他1个词条在 `## 4. 关联词条` 中引用（入度 ≥1）。 | 补充反向引用 |
| K03 | 弱连通图 | 术语百科整体构成弱连通图（任一词条可经关联词条链接到达另一词条）。 | 补充跨簇关联词条 |

## 2. 类型使用说明

- **编号**：`GXX`（通用类）、`SXX`（结构类）、`LXX`（链接类）、`CXX`（内容类）、`RXX`（关联与参考文档类）、`KXX`（知识图谱类）；类别内编号保留原序号（移除的通用条目见[《公共校验清单》](00_common_checklist.md)）。
- **校验范围**：[`docs/zh/knowledge_base/`](../../../knowledge_base/README.md) 各领域（子）目录下的 `term_*.md` 术语词条（词条就近放在所属领域目录）。
- **三类文档**：仓库按「领域-类别-词条」三层组织文档。词条文档（`term_*.md` / 量化格式 `<format_name>.md`）按本清单校验；类别词条与索引文档（`README.md`）不强制 `term_*` 命名，仅校验其结构，且不参与 K01（反向引用）/K03（弱连通图）的入度与连通性统计。
- **修复优先级**：G > S > L > C > R > K（通用与结构问题优先修复，避免后续连锁失败）。
