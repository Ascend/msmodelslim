# 流程指南校验条目

## 1. 使用方式

本文件定义流程指南的可校验规则，供编写人员自检和 Agent skill 调用。每条规则包含唯一编号、级别、校验对象和判定条件。

- **阻断**：等同于 error；仅用于可客观判断的结构或字段缺失，不满足时结论为“不通过”。
- **需修订**：用于内容质量、表达完整性或可执行性等需要判断的事项，不满足时结论为“需修订”。
- 标题以 `[OPTIONAL]` 开头的章节不参与必填章节校验。校验时先检查该章节是否存在；不存在则跳过其对应规则，存在才校验内容。

## 2. 阻断规则

| ID | 级别 | 校验对象 | 判定条件 |
| --- | --- | --- | --- |
| PG-ERR-001 | 阻断 | H1 标题 | 文档存在且仅存在一个 H1 标题。 |
| PG-ERR-002 | 阻断 | 核心章节 | 存在“适用范围”“输入和交付件”“操作步骤”三个核心章节。 |
| PG-ERR-003 | 阻断 | 输入与交付件 | “输入和交付件”章节同时包含至少一个输入项和至少一个交付件项。 |
| PG-ERR-004 | 阻断 | 操作步骤 | “操作步骤”章节包含至少一个步骤，且每个步骤同时包含“操作”和“输出”。 |

## 3. 通用需修订规则

| ID | 级别 | 校验对象 | 判定条件 |
| --- | --- | --- | --- |
| PG-REV-001 | 需修订 | 标题与范围 | 标题能表达流程主题；适用范围说明适用对象、场景或边界。 |
| PG-REV-002 | 需修订 | 输入与交付件 | 输入和交付件可定位，说明必要的来源、约束或验收方式。 |
| PG-REV-003 | 需修订 | 步骤闭环 | 步骤顺序合理；按需要补充输入、执行前检查、通过条件、审计记录和异常处置。 |
| PG-REV-004 | 需修订 | 命令与引用 | 命令、变量和路径有必要说明；引用的能力有证据来源。 |
| PG-REV-005 | 需修订 | 特殊场景 | 涉及精度、性能、安全、产品形态、资源、发布或运行时，说明相应的基线、限制、验收、监控或回退安排。 |

## 4. 可选章节规则

| ID | 级别 | 触发条件 | 判定条件 |
| --- | --- | --- | --- |
| PG-OPT-001 | 需修订 | 存在“流程关系与前置条件”章节 | 上级流程、前置条件和后续操作可理解且与流程相符。 |
| PG-OPT-002 | 需修订 | 存在“全局验收条件”章节 | 条目说明整篇流程级通过要求。 |
| PG-OPT-003 | 需修订 | 存在“全局异常处置”章节 | 条目说明异常现象、处理或回退方向。 |
| PG-OPT-004 | 需修订 | 存在“案例列表”“术语”或“接口文档列表”章节 | 每项仅保留名称和一句简述，且必须提供可跳转超链接；不以大段正文在本流程指南中展开细节。 |
| PG-OPT-005 | 需修订 | 存在“流程总览”章节 | 位于“操作步骤”之前，并包含流程图、mermaid 图或其他示意图。 |
| PG-OPT-006 | 需修订 | 存在“安全说明”或“产品形态与资源限制”章节 | 安全、产品形态或资源约束与流程实际风险、部署形态、依赖或容量相匹配。 |

## 5. 结论规则

1. 任一“阻断”规则不满足，结论为**不通过**。
2. 无阻断问题但存在“需修订”规则不满足，结论为**需修订**。
3. 所有适用规则均满足，结论为**通过**。
4. 输出校验结果时，必须列出规则 ID、问题位置、判定依据和最小修复建议。
