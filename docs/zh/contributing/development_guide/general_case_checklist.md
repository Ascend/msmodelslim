# 案例集校验条目表

用于评审新增或修订的案例文档。校验时以[通用案例模板](./general_case_template.md)为准，并核对与关联流程指南的衔接关系。

| 参考模板 | 路径 |
| --- | --- |
| 通用案例模板 | [general_case_template.md](./general_case_template.md) |
| 流程模板 | [process_guide_template.md](./process_guide_template.md) |

**使用方式**：对每条填写「是 / 否 / 不适用」；标「否」须在备注中说明原因或整改项。可选章节未编写时，对应条目填「不适用」。下文「对应模板 §1」等写法中，§ 表示章节编号（§1 即第 1 节，§6–§7 即第 6–7 节），与[通用案例模板](./general_case_template.md)章节对应。

---

## 1. 文档形式与占位符（对应案例模板约定）

| 序号 | 校验条目 | 结果 | 备注 |
| --- | --- | --- | --- |
| 1.1 | 文件命名符合约定（`{model_name}_{scenario_type}_case.md`），标题为 `{model_name}-{scenario_type}案例` 可读形式 |  |  |
| 1.2 | 正文中无未替换的 `{{placeholder}}` |  |  |
| 1.3 | 模板说明类注释（`> **注释：** …`）已全部删除；非模板说明的必要图注/版权说明可保留 |  |  |
| 1.4 | 未保留的 `[OPTIONAL]` 章节已整节删除，未留空壳标题；保留章节标题中无 `[OPTIONAL]` 前缀 |  |  |
| 1.5 | 章节编号连续，结构与案例模板主线一致（背景 → 环境与版本 → 输入和交付件 → 操作步骤 → 结果与经验） |  |  |

## 3. 环境与版本（对应模板 §2）

| 序号 | 校验条目 | 结果 | 备注 |
| --- | --- | --- | --- |
| 3.1 | 环境与版本表已填写本次实际依赖，含「产品形态」项，非空泛描述 |  |  |
| 3.2 | 产品形态已写明（如Atlas 800I A2），并标明是否限定；限定时写明适用边界 |  |  |

| 3.5 | 「本次前置事实」仅为案例开始前已满足的事实，非空泛或流程级条款 |  |  |

## 4. 输入和交付件（对应模板 §3）

| 序号 | 校验条目 | 结果 | 备注 |
| --- | --- | --- | --- |
| 4.1 | 输入与交付件分项列出，表头含：类型、名称、来源或保存位置、格式或约束、验收方式 |  |  |
| 4.2 | 每项来源或保存位置可定位（路径、链接或明确获取方式；交付件如量化权重结果对应实际输出目录） |  |  |
| 4.3 | 每项「格式或约束」已填写且可核对（如兼容性保证、内容组成、任务匹配等） |  |  |
| 4.4 | 每项具备可验证的验收方式；量化权重类交付件含 md5 或 safetensors 比对结果（或等价可核对方式） |  |  |
| 4.5 | 填写的是本案例实际取值，而非未落地的占位说明或模板示例原文 |  |  |
