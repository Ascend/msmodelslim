# 量化术语百科词条 Checklist

本文用于校验基于[《量化术语百科词条模板》](quantization_glossary_template.md)新建或整改的术语百科文档。提交文档前，应逐项确认；不适用的可选项可标记为 `N/A` 并说明原因。

> 使用约定：
>
> - 校验条目以 `GXX`（通用类）、`SXX`（结构类）、`LXX`（链接类）、`CXX`（内容类）、`PXX`（原理与公式类）、`RXX`（关联与参考资料类）编号。
> - 严重级别分为 **ERROR**（必须修复，不通过则校验失败）与 **WARN**（建议修复，不通过仅告警）。
> - 校验范围：`docs/zh/user_guide/quantization_glossary/term_*.md` 及其多语言对应目录下的术语词条。

## 8. 校验执行说明

1. **触发时机**：
   - 新增术语词条后立即触发全量校验。
   - 修改已有术语词条后触发增量校验（仅校验变更文件 + 受其引用关系影响的文件）。
   - 资料 skills 在执行“资料校验”命令时统一触发。
2. **校验输出**：以表格形式输出 `[编号] [严重级别] [文件] [条目] [失败原因] [修复建议]`，ERROR 项导致校验整体失败，WARN 项仅提示。
3. **修复优先级**：G > S > L > C > P > R > K（通用与结构问题优先修复，避免后续连锁失败）。
4. **豁免机制**：如某词条确有合理原因无法满足某条目（如纯概念术语无公式），可在文件顶部以 `<!-- waiver: P02 原因：xxx -->` 形式声明豁免，skills 校验时跳过对应条目并记录豁免原因；豁免声明不得用于规避 ERROR 类条目超过 2 项。
5. **本清单与模板同步演进**：模板新增/调整章节时，本清单须同步新增/调整对应校验条目。

| 编号 | 严重级别 | 校验条目 | 校验方法 | 失败处理建议 |
| :--- | :--- | :--- | :--- | :--- |
| A01 | ERROR | 文中不得出现常见错别字（如“的得地”误用、“从而”写成“从尔”、“部署”写成“部暑”、“量纲”写成“量刚”等）。 | 中文错别字词库匹配 | 修正错别字 |
| A02 | ERROR | 中英文混排时，中文与英文单词之间应有空格，中文与数字之间也应有空格；但英文单词与标点之间、数字与百分号之间不加空格。 | 正则匹配中英文/中数之间缺少空格的情况 | 补充空格 |
| A03 | ERROR | 标点符号必须全半角统一：中文内容使用全角标点（。，、；：？！“”''（）——……），英文/数字/公式上下文使用半角标点（.,;:?!\"'()）。 | 扫描标点符号的上下文一致性 | 统一标点风格 |
| A04 | ERROR | 句子成分完整，无残缺句（缺少主语、谓语等）、无杂糅句式（多个句式混在一起）。 | 句法结构分析或关键词启发式检测 | 重写有问题的句子 |
| A05 | WARN | 同一术语在全文中的表述应一致，禁止同一含义使用不同名称混用（如“离群值”和“异常值”混用、“量化”和“压缩”混用），除非有明确区分说明。 | 抽取术语出现频率，检测同一概念的多词混用 | 统一术语命名 |
| A06 | WARN | 数字格式应统一：大数字建议每三位加逗号或使用中文单位（如“10,000”或“1万”），避免“10000”与“10,000”混用。 | 正则匹配数字格式 | 统一数字格式 |
| A07 | ERROR | 文中不得出现明显不通顺的语句（如主谓不搭配、动宾不搭配、多重否定导致语义混乱）。 | 语义通顺度模型评分或人工审校 | 重写不通顺语句 |
| A08 | WARN | 列表项（`-` 或 `1.`）的句式应保持平行结构（同为名词短语/同为动词短语/同为完整句），避免混用。 | 检测列表项首个词的词性一致性 | 统一列表项句式 |
