# 新增场景索引（机制）

> 本目录定义资料管理 skill 的"新增场景"机制：每种新增场景一个场景文档，声明目标目录、要插入的模板、命名规则与（可选的）场景特有校验清单。**具体场景文档后续逐步补充，当前仅保留机制。**

## 机制说明

skill 新增资料时读取本索引：

- **命中**某场景文档 → 按该文档的 `target_dir` / `templates` 与正文`操作步骤`执行（建目录、插模板）；校验时**分别执行场景特有校验清单与文档类型清单并综合结果**。
- **未命中** → 只推荐用户操作（应有的目标目录、模板与校验依据），不建目录、不插模板（见 SKILL.md 红线）。

## 场景文档 schema

每个场景文档以 YAML frontmatter 声明配置，正文以步骤说明具体操作：

| 字段 | 含义 |
| --- | --- |
| `name` | 场景唯一标识（kebab-case），须与文件名一致。 |
| `title` | 场景名。 |
| `triggers` | 用户诉求触发关键词，供 skill 匹配场景。 |
| `target_dir` | 目标目录（仓库相对路径）；`<占位>` 按命名规则替换。 |
| `create_subdir` | 是否新建子目录。 |
| `templates` | 要插入的模板（`docs_standards/` 下 `NN_*_template.md`）→ 目标文件名模式。 |
| `naming_rules` | 目录 / 文件命名规则。 |

正文至少包含 `## 目标形态`、`## 命名规则`、`## 操作步骤`、`## 校验依据`。**场景特有校验清单**（可选）写入正文 `## 场景特有校验清单` 小节，**仅列该场景特有、文档类型清单未覆盖的条目**（不重复类型清单）；校验时与插入模板对应的文档类型清单分别执行并综合结果。

样例：见 [example.md](example.md)（示例场景文档，非已登记真实场景，供新增场景时复制改写）。

## 如何新增场景

1. 场景目标目录、模板、校验口径须可在资料规范（`docs/zh/contributing/development_guide/docs_standards/README.md`）中追溯；规范未定义的结构先更新规范再登记场景。
2. 复用 `docs_standards/` 下既有模板；如需场景特有校验清单，写入正文"场景特有校验清单"小节，仅列该场景特有条目，不重复文档类型清单。
3. 新建 `<name>.md`，按上表 schema 填写，并在本 README 登记（可另建"场景清单"小节维护索引）。
4. 规范变更时同步更新对应场景文档。

## 与 skill 的配合

- skill 职责 1.1 读取本索引定位场景：命中 → 读场景文档配置并执行；**未命中 → 只推荐用户操作，不建目录、不插模板**（见 SKILL.md 红线）。
- 场景文档只描述"目标形态 + 操作步骤"，不包含既有文档内容，避免与资料校验冲突。
