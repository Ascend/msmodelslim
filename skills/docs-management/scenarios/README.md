# 新增场景索引（机制）

> 本目录定义资料管理 skill 的"新增场景"机制：每种新增场景一个场景文档，声明目标目录、要插入的模板、命名规则与（可选的）场景特有校验清单。**具体场景文档后续逐步补充，当前仅保留机制。**

## 机制说明

skill 新增资料时读取本索引：

- **命中**某场景文档 → 按该文档的 `target_dir` / `templates` 与正文`操作步骤`执行（建目录、插模板）；校验时**分别执行场景特有校验清单与文档类型清单并综合结果**。
- **未命中** → 只推荐用户操作（应有的目标目录、模板与校验依据），不建目录、不插模板（见 [SKILL.md 红线](../SKILL.md#红线)）。

## 场景文档 schema

每个场景文档以 YAML frontmatter 声明配置，正文以步骤说明具体操作：

| 字段 | 类型 | 必填 | 默认值 | 含义 |
| --- | --- | --- | --- | --- |
| `name` | string | 是 | — | 场景唯一标识（kebab-case），须与文件名一致。 |
| `title` | string | 是 | — | 场景名。 |
| `triggers` | string[] | 是 | — | 用户诉求触发关键词，供 skill 匹配场景。 |
| `target_dir` | string | 是 | — | 目标目录（仓库相对路径）；`<占位>` 按命名规则替换。 |
| `create_subdir` | boolean | 否 | 未声明时不建子目录 | 是否新建子目录。 |
| `subdir_name` | string | 否（`create_subdir: true` 时必填） | — | 新建子目录名（英文小写，多词以下划线连接，与目标目录既有文档命名一致）。 |
| `templates` | object | 是 | — | 要插入的模板（`docs_standards/` 下 `NN_*_template.md`）→ 目标文件名模式。 |
| `naming_rules` | string | 是 | — | 目录 / 文件命名规则。 |

正文至少包含 `## 目标形态`（新增后的文档结构与位置）、`## 命名规则`（目录 / 文件命名规则）、`## 操作步骤`（具体动作与顺序）、`## 校验依据`（本场景校验清单口径）。**场景特有校验清单**（可选）写入正文 `## 场景特有校验清单` 小节，**仅列该场景特有、文档类型清单未覆盖的条目**（不重复类型清单）；校验时与插入模板对应的文档类型清单分别执行并综合结果。

样例：见 《[新增示例场景](example.md)》（示例场景文档，非已登记真实场景，供新增场景时复制改写）。

## 如何新增场景

**前提**：场景目标目录、模板、校验口径须可在资料规范（`docs/zh/contributing/development_guide/docs_standards/README.md`）中追溯；规范未定义的结构先更新规范再登记场景。

1. 复用 `docs_standards/` 下既有模板；如需场景特有校验清单，写入正文"场景特有校验清单"小节，仅列该场景特有条目，不重复文档类型清单。预期产物：正文章节骨架。
2. 新建 `<name>.md`，按上表 schema 填写，并在本 README 登记（可另建"场景清单"小节维护索引）。预期产物：一份可被 skill 识别的场景文档 + 索引登记。
3. 规范变更时同步更新对应场景文档。预期产物：场景文档与规范保持一致。

## 与 skill 的配合

- skill 职责 1.1 读取本索引定位场景：命中 → 读场景文档配置并执行；**未命中 → 只推荐用户操作，不建目录、不插模板**（见 [SKILL.md 红线](../SKILL.md#红线)）。
- 场景文档只描述"目标形态 + 操作步骤"，不包含既有文档内容，避免与资料校验冲突。
